# 云卡 v2 · 第 6 幕（晨）· 第 8 / 8b 幕（暮、蓝时）· lookdev brief

写的人：云端会话「云」（分支 `pkg/clouds`），2026-10-22 起。依据：圣经 v2.1 §1.3、§1.6、§1.8、§6·5→6、§6·6、§6·7→8、§6·8、§6·8b、§6.x、§8.1 #4 / #9b、§8.2；`Art/palettes/Palette_06/08/08b`；`calib_final.md` §B；`Grading/`（引擎参数）。

## 1. 要达到什么（一句话）

- **晨**：一个巨大、苍白的早晨——白上的藍与金。云的受光面桃金，阴影是**藍灰 `#8593AA`**（h 272，C\* 14），绝不紫、绝不褐。
- **暮**：暖只在光里，阴影里只有靛——云影**靛石 `#363D59`**；上下两组云一起慢慢向下滑，读出 +3 m/s 的上升；“另一片天”不是倒影。
- **蓝时**：蓝来自天空资产；云跟着天一起冷下去、暗下去。

## 3. 管线（为什么这样做）

1. **天**：`Clouds_v2/Source/sky_fit.py` 把本地选定的两张 HDRI（晨 `syferfontein_6d_clear_puresky`，暮 `syferfontein_0d_clear_puresky`）按圣经的屏幕目标拉过去（按仰角分带的乘色，日侧 / 侧面 / 背日三条曲线），得到“场景线性的目标天”。这是**云卡被什么天照亮**、参考渲染用什么天。正式的 `Lanbai/Sky` 归天空会话：我把拟合出的曲线和目标给它（`给总控.md`）。
2. **云卡**：Blender 5.0.1 Cycles 体积（沿用 v1 的形状与 alpha 清理）。每张卡分两遍渲：**只有太阳**、**只有天**（各自降噪），然后按每个预设一组固定的增益合成——增益是用代表卡（积云、侧光）对着云影与云顶两个屏幕目标解出来的，同一个预设的所有卡用同一组（光是一致的，不是逐卡调色）。
3. **导出**：场景线性，不 tonemap。PNG = sRGB 编码的 `线性 × 2^−2.5`，直通 alpha；shader 里 `× 2^2.5`。（圣经写 −1 EV / ×2；晨的云顶在 S6 下要场景线性 R ≈ 4，装不下，见 `给总控.md`。）
4. **参考渲染**：numpy 把 `Lanbai/CloudCard` 的数学原样移植（公告板、雾、底部融化、软粒子），叠上目标天、`Lanbai/Sea` 的近似、车厢剪影，按 PPv2 引擎模型调色。Unity 用同一套数，本地截图可以逐像素对照。

## 4. 参照（看什么）

- 晨：高空飞行时日出后十分钟的积云原（低日、长影、云顶的桃色、阴影的冷灰蓝）；Maxfield Parrish 的天但不要他的粉；吉卜力《风之谷》开场的云海。
- 暮：乌尤尼是反例（圣经明说不要镜子）；要的是“亦若是”：上下各是一片完整的暮天，下面的云是别的云。
- 规避：v1 的薰衣草阴影（`#8E8FB5`）、紫红暮影（`#4A3560`）；“蒸汽波日落”；褐色烟边。
