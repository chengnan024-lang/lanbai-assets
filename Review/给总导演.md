# 美术审片 → 总导演（要你定的事、和你可能不同意的事）

> 每条：问题 · 我的建议 · 为什么要你定（圣经条文 / 跨包）。你定了，我按你的决定审；你不同意，写在下面那条的“回复”里。最新的在最上面。

## 2026-10-23 · 门的练习审片带出来的五件事（详情 `练习_门定稿/审片意见.md`）

### 1. 被伤口光照到的车厢是丁香紫（跨包：门 × 车厢 × 圣经）
- 门的 U8b：顶棚 L\* 37 / C\* 20 / h 293，最大的连续块占画面 4.45%，比伤口本身（C\* 1）和光斑（C\* 7）都紫，读成“紫色氛围灯的室内”。
- 这不是门擅自染的：它就是圣经 §6·4 的裂口光 `#A99DE1`（E 0.8，只照车厢层）照在圣经 §4.2 的天花 `#E2DDCF` 上算出来的。圣经 §1.3 第 4 条对第 4 幕只限制了“C\* > 30 的紫 ≤ 10%”，所以按条文不违规。
- 但圣经在 S4 的说明里自己点名过 v1 “连车厢一起染了”是错的；而车厢在头显里是 360° 包住人的，你的车厢在第 4 幕会整片变成这个颜色。
- **建议**：圣经 §1.3 第 4 条补一句“伤口的光照到的车厢面 C\* ≤ 12、h 230–290”；车厢层的裂口光改为去饱和的 `#B9B6D6` 左右（或者强度降到顶棚 L\* ≤ 25），伤口一侧的内缘轮廓保留 `#A99DE1`。你的车厢 shader（`pkg/cabin`）照这一条做；门的渲染跟着改。

### 2. JSON 的灯光强度只给 E（跨包：所有包）
- 本地实测 VRChat 强制线性强度，门的补光在 Unity 里实际是 0.52，不是设计的 0.24，臂的顶面因此偏蓝紫（Unity 的强紫 0.12%，定稿 0.01%）。CONTROL §3 已经写了“Inspector 值 = E”，但门的 JSON `lights` 还是 gamma 那一栏。
- **建议**：所有包的 JSON 只给 E 一栏（Inspector = E），门在 `pkg/gate-clouds` 这一轮顺手改；补光一律 Not Important（圣经本来就这么写），本地重测时关掉 ForwardAdd 的那一份。

### 3. 第 4 幕天上有没有星（门 × 天空 × 本地）
- 圣经 §6·4：星图增益 0.12，光雾带里再暗 1 EV。定稿没有星，Unity 的 GateAirSky 默认画出了稀疏的星，本地以为自己错了。
- **建议**：按圣经保留，足迹 ≥ 1.5 px（单像素的星在头显里会闪）、L\* ≤ 12；门的 JSON 写死这个值，定稿补上，天空的 `LanbaiSky` 在第 3c → 4 的接缝上用同一套星。

### 4. 里尔克的诗、巨像 1 和车的右 A 柱撞在一起（跨包：车厢 × 门 × 圣经 §7.5）
- 门的占位车壳，右 A 柱 / 门框正好挡在方位 +19…+31°：里尔克在 +20° / +3°（每行宽到 28°），巨像 1 在它身后升起，两样都在柱子后面。这是第 3 → 4 幕最重要的一拍（“美不过是恐怖的开端”，预言）。
- **建议**：真车壳的 A 柱位置一定，就和诗的方位一起定（诗中心离柱 ≥ 4° + 半行宽）；在那之前圣经 §7.5 先把里尔克挪到 +12° / +3°，巨像 1 跟着诗走。你的车厢会决定这件事，请在 `pkg/cabin` 交的第一版里给出从主座位看的 A 柱方位。

### 5. 近处触手要多粗（门的 §11.1 M5 一直没人拍板）
- U8 时近臂从侧窗掠过，与眼同高的是它细的中上段，读成“缆绳 / 杆子”（陌生人测试：“一根细长的深色弯杆像钩子”）。门说要看到粗的身体就得改近层的尺度阶梯，“留给 AD 决定”，到现在没人定。U8 是全幕唯一的近距离震撼。
- **建议**：近层在与眼同高的那一段至少 250 px 宽的身体（1080p），粗段上移到窗高；仍守 ≥ 8 m、相对速度 ≤ 1.05 d。定了写进 v2.3 的“近层”一行。
