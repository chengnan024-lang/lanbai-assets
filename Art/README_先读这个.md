## 1. 必须守的（这是"法律"）

- **屏幕上的颜色目标**：每一幕的色板（`palettes/`），以及文中标"屏幕目标"的 hex。参数只是起点，调参数去追目标，**目标本身不改**。
- **调色管线** §1.4：PPv2 用 **HDR 模式 + Neutral tonemapper**，每一幕一个 profile，volume 之间交叉淡化；**只让发光体 bloom**。永远不用 ACES，不开 Auto Exposure、Motion Blur、DOF、色差。
- **VR 舒适铁律** §1.8，**没有例外**：闪烁次数、亮度爬升律、白光峰值、运动速度，VR 里不许有任何锁屏效果。
- **画面语法** §1.3：每帧只有一个最亮点；**紫色只出现在第 4 幕**；暖色是配给的；地平线永远水平；什么都不许碰到车。
- **反照率纪律** §1.6。

## 2. 由你决定的（圣经里是建议）

- **实现架构**：跑步机（车固定在原点、世界从旁边移过）、Director 的结构、自定义 shader 怎么写、曝光助手 volume 的公式、遮罩球等等，都是我们为了达到画面目标给的**一种做法**。**现有 build 里已经能用的系统，不要为了圣经去重写。** 只要最后截图对上目标、VR 规则守住就行。要改大的架构（比如把会移动的车改成跑步机），先在 `FromLocal/` 写一句，我们商量。
- 文中所有数值（灯光强度、雾密度、粒子数量……）都按灰卡和截图来调。

## 5. 这一版里最重要的几个美学决定（一眼看懂）

- **蓝白是一场把夜"褪色"的梦**：从雨夜最深的靛开始，一路褪到「藍白」（`#E8F1F5`，从来不到纯白），最后回到深处，天边留一线浅。
- **天海互镜**：往下看和往上看一样。湿路、水田、海面、海的底面、暮色里的"另一片天"、铜镜、倒悬的海、水洼，都是镜子。
- **克制对压倒**：每个高峰前面至少留 10 秒低谷。画框随着宏大一步步变宽：车窗 → 天窗 → 顶棚破洞 → 没有墙 → 什么都没有。
- **触手之门**：裂口的核心是"未染的白"，靛蓝的布被撕开，露出底下没被染过的白；两侧有一条冷的光雾带；巨像在 *…und wollt' mich abweisen* 上挡住月亮；到 *Ach nein!* 时裂口大过挡风玻璃，要抬头从车顶天窗看它。
- **宏大在旅途，眼泪在归来**：银河变成萤火虫，铜镜变成水洼，天空的裂口变成一根灯管。
