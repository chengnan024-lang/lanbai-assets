# 镜子套件 · 内部约定（网格、贴图、shader 之间的接口）

所有生成脚本、shader、numpy 移植都按这一页。改这一页 = 改接口，要同时改三边。

## 1. 网格 `BronzeMirror`（直径 D = 1 的单位网格，按直径整体缩放）

- 物体空间：米（D = 1），**Y 上**，镜面朝 +Y，原点在镜心、**y = 0 是镜面边缘（r = 0.48）的高度**。Unity 里 `localScale = D`（均匀）。
- 剖面（r = 到 Y 轴的水平距离）：

| 区 | r 范围 | y | 区号（顶点色 R） |
|---|---|---|---|
| 镜面（球冠） | 0 – 0.48 | y = sqrt(ρ² − r²) − (ρ − s)，s = 0.015（矢高 1.5 % D），ρ = (0.48² + s²)/(2s) = 7.6875；镜心 y = 0.015 | 0.0 |
| 镜缘带顶面（连珠乳钉在 shader 里） | 0.48 – 0.50 | 平，y = +0.002；内外各 0.001 的倒角 | 0.25 |
| 外侧壁 | r = 0.50 | 从 y = +0.002 到 y = −0.037 | 0.5 |
| 镜背：宽平缘 | 0.425 – 0.50 | y = −0.037（缘厚 3.7 % D，从镜面边缘算） | 0.75 |
| 镜背：缘内斜坡 | 0.415 – 0.425 | −0.037 → −0.015 | 0.75 |
| 镜背：主区（平） | 0.065 – 0.415 | y = −0.015 | 0.75 |
| 钮（半球，略高于半球的馒头形） | 0 – 0.065 | 从 −0.015 到 −0.065（钮顶），钮孔：沿 **物体 X 轴**穿过的矩形孔，宽 0.022、高 0.014，孔心 y = −0.030 | 1.0 |

- 法线：区与区之间硬边；镜面的法线由 shader 解析算（球冠），网格法线只是备用。
- UV0 = 物体 (x, z) + 0.5（俯视平面投影，镜面贴图用）；UV1 不用。顶点色 RGBA：R = 区号，G = 0，B = 0，A = 1。
- 镜面环的分布要在镜缘附近加密（反射在掠射角最敏感），镜心稀。LOD0 / LOD1 / LOD2：圆周 512 / 256 / 128 段，镜面径向 64 / 32 / 16 圈。
- 朝向：物体 +Z = 镜背博局的“北”（玄武），+X = 东（青龙）。从下往上看镜背时，东在右手边要反过来——按物体空间画，不要按“从下看”画。
- FBX：`Mirrors/Models/BronzeMirror.fbx`，根空物体 `BronzeMirror` 下 `BronzeMirror_LOD0/1/2`（Unity 不自动建 LODGroup，搭建脚本建，CONTROL §6 第 4 条）。导出设置照 `Tentacles/Source/lib/export_unity.py`。

## 2. 镜背贴图（一格博局 = 40 m × 40 m，绝对尺寸平铺）

- shader 里：`cell = (objPos.xz × D) / 40 + 0.5`（D = 直径米），`uv = frac(cell)`；镜心那一格的中心 = 镜心。
- `T_MirrorBack_Normal_2048.png`：切线空间法线（OpenGL 约定 +Y 上，切线 = 物体 +X，副切线 = 物体 +Z；镜背朝下时 shader 自己翻转），Unity 导入为 Normal map。
- `T_MirrorBack_Mask_2048.png`（线性，sRGB 关）：R = 高度（0–1，1 = 0.016 D 当 D = 40 m 时 → 绝对 0.64 m），G = AO / 凹处（1 = 不遮），B = 磨亮遮罩（凸起的棱 = 1：铜绿被磨掉、露出暗铜），A = 铜锈变化（0–1，粉绿 / 蓝绿 / 红斑的低频斑块）。
- 一格的内容（格坐标 u, v ∈ [0, 1]，格心 (0.5, 0.5)；第 1 面 R = 20 m = 半格，所以 r/R → 格半径 0.5·r/R）：
  - 格心：柿蒂纹钮座（四叶，叶尖指向格角），**格心本身不画钮**（钮是网格，只在镜心）；在其他格的格心画一颗**大乳**（半径 r/R 0.06）代替钮。
  - r/R 0.24 – 0.40：双线方框，框内十二小乳 + 十二地支（子在北 +v，顺时针：子丑寅卯辰巳午未申酉戌亥，每边三字，阳文）。
  - T、L、V、八乳、四神（东青龙 +u、西白虎 −u、南朱雀 −v、北玄武 +v）+ 羽人 / 禽兽，细线低浮雕：照 `lookdev_brief.md` §4 的表。
  - r/R > 0.72 的格角：流云纹 + 小乳填满，让相邻格接得上（格边连续：u = 0 和 u = 1 的高度相等）。
- 外圈纹带（铭文、栉齿、锯齿、波折）**不在贴图里**，shader 按镜子的真实半径在极坐标里画（§3）。

## 3. 极坐标纹带（shader 程序化，绝对尺寸）

R = 镜半径（米），r = 到镜心的水平距离（米），θ = atan2(z, x)。纹带的位置是 r/R（随镜子缩放），纹样的周期是米（不缩放）：

| 带 | r/R | 周期 |
|---|---|---|
| 铭文（尚方镜铭 35 字，环读，逆时针） | 0.72 – 0.80 | 字距 2.4 m；带宽超过 1 行时往里一圈圈重复（行距 2.6 m） |
| 栉齿 | 0.80 – 0.83 | 0.5 m |
| 宽平缘：锯齿 — 双线波折 — 锯齿 | 0.85 – 1.00 | 齿距 1.25 m（三个子带各占 1/3） |
| 镜面一侧的镜缘带：连珠乳钉 | 0.96 – 1.00（物体 r 0.48 – 0.50） | 1.5 m，乳钉直径 0.6 m，在带的中线 r = 0.49 D |

## 4. 镜面贴图 `T_MirrorFace_2048.png`（UV0，随镜子缩放）

线性，sRGB 关：R = 光滑度偏移（−0.02 … +0.02 编码为 0 … 1，0.5 = 0），G = 色调偏移（0.5 = 无；暖 / 冷 ±3 %），B = 发丝划痕遮罩，A = 水银沁斑（富锡的银白斑，光滑度 +0.01、F0 偏冷）。低频为主：一面 40 m 的镜子上斑块 3–8 m。

## 5. 字形图集 `T_MirrorGlyphs_1024.png`

8 × 8 格、每格 128 px，R = 字的覆盖（1 = 笔画）。前 35 格 = 尚方镜铭（顺序见 `lookdev_brief.md` §4），36–47 = 十二地支。字形用仓库里的思源宋体加粗、方折处理成近似缪篆的方笔（我们没有可用的缪篆字体：已知弱点）。

## 6. 运行时参数（MaterialPropertyBlock，每面镜一组）

`_RadiusM`（米）、`_MirrorK`（序号 1–13）、`_EmissionK`（0.2 + 0.08 k）、`_Visibility`（0–1）、`_EmitExtraEV`（第 13 面 0–3）、`_Appear`（0–1，凝聚）、`_Dissolve`（0–1，溶解）、`_RimSoft`（0–1）、`_RimSoftFrom`（柔化从半径的几成开始）。`_StencilRef`（64 + 槽位）是渲染状态，**只能在材质上**（每面镜一个材质，搭建脚本设好），不能用 MPB。全局：`_Udon_GalaxyGain`、`_Udon_StarGain`、`_Udon_MirrorPlane`。
