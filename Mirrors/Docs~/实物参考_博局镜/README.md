## 怎么用（建议）

1. **核对考据里的比例**：`research_tlv_form.md` §1 的 r/R（钮、钮座、方框、乳钉、铭文带、栉齿、缘）标着【经验值】。可以直接在 1995.298 和 1995.301 上量一遍，把【经验值】换成实测。
2. **镜背纹样的来源**：浮雕转成高度图和法线贴图。真东西铸造的不规整、磨平的纹、铭文带，程序生成很难做出来。注意这些是博物馆打光的照片，高光和阴影已经烘在里面，直接转高度会把光当成形状；建议照着描成矢量或高度，或者至少先去光照。
3. **尺寸照圣经，不照原物**：圣经 §6·9 要求乳钉恒定 1.5 m 一颗、TLV 纹按直径 / 40 m 平铺，用纹样的疏密读出“一面比一面大”。真镜只当纹样来源，尺寸和密度按圣经与 D-01（82 颗、博局格、第 13 面 2.4 km）。
4. **镜面那一面**：照片拍的都是镜背。镜面（白铜 `#D6CCB4`，光滑度 0.94，凸 1.5%）照圣经做，鎏金那面（1995.294）可以帮着判断金属光泽。
