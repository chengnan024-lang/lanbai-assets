## 1. 日线（`LanbaiSunTerm` 的线模式）

以前：一根亮度均匀、两头平切的管子（±10° 内 233–237，两头 0.6° 内断掉，芯约 0.42° 宽）。现在：

- **太阳处最亮，往两头渐暗**：芯的亮度沿线按 (1 − u)^2.5 走，u = 到太阳的方位距 / (线半长 + 日盘半径)。正前方中线（不含 bloom）：方位 0 / 2 / 5 / 8 / 10 / 12° = 234 / 219 / 183 / 148 / 138 / 128（后几个已经是天本身）。
- **两端是羽化的尖头**：芯的半宽从日盘半径（0.265°）收到 0.3 倍，亮度同时到 0。
- **芯的宽窄有变化**：一组按方位的固定正弦纹（`LanbaiLineRipple`），±18%。
- **外面一层宽光晕**：0.35° 和 1.2° 两个高斯，比芯长 25% + 1.5°，接住 bloom。
- **990 读成“烧尽”**：「云」的收缩是增益和长度一起按 `k = 1 − smoothstep((t − F12) / 6)` 走。增益 < 1 时芯变细（到 55%），按另一组**天上固定**的纹理不均匀地熄，光晕比芯留得久。因为纹理固定在天上，线是在纹理里烧短，不是一根均匀的管子缩短。
- **D-39 的“只有一条线”照旧**：下半球的另一片天用同一个函数，太阳在 0° 时两条重合。时间曲线以「云」那边为准，天空不改它。

## 2. 暮 HDRI 太阳右边的台阶

台阶在太阳右边约 2.5°、仰角 0 … +1.5°，L\* 65 → 52（约 13），陡到 9.3 L\*/度。做法：`_SunRemove` 的补图模式扩成**椭圆**（w > 0 = 仰角半高），暮用 (14, 0, 0, 2.5)。太阳周围方位 ±14°、仰角 ±2.5° 内，每一行按同一仰角在椭圆左右两边之间插值。结果：0 … 0.5° 那几行最陡 1.6 L\*/度；+1° 那一行 2.5 L\*/度（在 +10.7°，是另一道缓的云边）。HDRI 自己的日斑也一起被补掉，日盘和日晕是程序化的（8-i 增益 1）。晨的圆（w = 0）逐位不变。

## 3. 蓝时

| 要求 | 以前 | 现在 |

| 地平线的缝回来，最亮的带不能在地平线下 6–8° | 0° 处 L\* 50，−6 … −10° 处 53（最亮） | **0° 处 55 最亮**，上 1° 49、下 1° 52（一道缝）；往上、往下都暗下去 |

| F12 那条藕紫带 | 8-ii 中天 h 350–360、C\* 18–25；淡变里品红 h 347 | 0（h 330 … 8 且 C\* > 12 的仰角范围：8-ii 和淡变都是 0） |
| 8-ii 约 8% 面积红通道溢出 | 8.5%（正前方，只有天） | **4.0%**（立方图 −0.3 EV、日晕小一些） |

改了什么：
- 蓝时的带 1 中心以下 σ 10 → 5（它的尾巴压暗地平线比压暗下面多，最亮的一行才会落到地平线下）。地平线往上、往下的渐变幂 0.8 / 1 → 0.3 / 0.3（缝）。背日那头的地平线色 0.80 → 0.62（日侧）。
- **从暮淡到蓝时按方向走**（`LanbaiProcWeight`）：天顶和天底先换、地平线最后，每个方向只用 6 秒的四分之一。程序化天的带 1 跟着它按方向进来，暮的玫瑰带（带 2）跟着立方图按方向走。以前整片一起淡，淡到一半整条玫瑰带是半蓝半粉的灰藕色。
- 蓝时预设里立方图的参数（乘色、旋转、EV、日斑补图）抄暮的。蓝时自己用不到，但淡变里暮的图不再被拉向原图那种偏紫的粉。
- 紫护栏（三个暖天共用）的中段改成淡银蓝 → 桃奶油色，玫瑰保持绿 ≥ 1.08 × 蓝。晨也用这个护栏：只有天的 APL 升约 0.2（正前方 169.0 → 169.2），紫带仍是 0。**D-35 第 6 幕的数是用旧护栏量的，合并时总导演复核。**
- 量（只有天）：993.06 正前方 APL 85（以前 103）。「云」的 ΔEV −1.5 不变时，1001.21 是 49.6，正好在「云」的目标 50 上。

## 第 8 幕终审（天空这边，审 2450a18）的修改

- **A1 F12 暮 → 蓝时**：以前紫护栏跑在混合以后，它很陡的过渡段把半玫瑰半蓝的颜色推到一头，就成了一道约 1° 的硬边从天顶往下扫。现在两头**各按自己的预设样子**渲（暮：立方图 + 完整护栏；蓝时：程序化 + 软护栏，在蓝时自己的颜色上和完整护栏差 < 1 dE），按方向在对数空间混合（天顶 / 天底先 1.5 s，每个方向 4.5 s、方向内线性，整片天同时都在变，没有扫过的边），混合本身造出的淡紫用连续的 `LanbaiPurpleGuardSoft` 去掉。按 0.25 s 渲 986 → 994（`act8_fade_986_994.png`；量的时候 0.125 s 一帧）：
  - 每个像素从变化的 10% 到 90% 至少 2.0 s（地平线 2.4 s，中位 2.6–3.1 s），以前地平线 ≤ 0.25 s；
  - 淡变开始和结束那一帧和静态预设差 < 0.4 dE；淡变里整球紫带 0（序列测试）。
  - 「云」的淡变是 6 秒（F12 → 993.06），所以每个方向做不到圣经的 ≥ 8 秒；要更长得「云」把淡变拉长，天空这边不用改。
- **A2 蓝时 +14° 的台阶**：单调带中心以上那一支 6° 内平滑接进来，最陡 1.7 L\*/度。
- **F1 959.36 日线长出来那一帧**：线在最初 1° 里从日盘长出来（日盘与线按 saturate(半长 / 1°) 插值）。90 Hz 逐帧 959.30 → 959.60：日心周围每帧最大变化 0.004 EV；整个生长 959.3 → 965 每帧最多 0.04 EV（线头扫过的那一点）。
- **F2 第 9 幕往回拖**：驱动记上一帧的 t，往回跳就清掉 `_full`，下一帧先 `Apply(blue_hour)` 再写自己的；README_集成 §9.5 的验收加了 1100 → 1005 和拖回 1001.21 … 1009.21。
- **F7**：日线的纹理 / 芯 / 光晕只在线的范围里算（仰角 ±6°、方位在光晕长度内），别处只算日晕。
- 别的预设逐位不变（只有 `blue_hour` 的图变了，A2）。
- **淡变中间不发青**（总导演复审，990–991.5 粉带上方的青绿灰）：淡变里绿压过红、而蓝压过绿不如蓝时自己的蓝那么多的颜色（调色后 h < 约 262，青的那一侧），拉向同亮度的低饱和中性灰蓝（`LANBAI_FADE_CYAN`）。按 0.25 s 重渲 989 → 992，正前方和抬头 35°：h 150–220 没有一个像素；h 150–262 且 C\* > 6 只在 989.00 一处（下半球 −13.7°，h 正好 262，是暮自己的颜色，淡变还没到），989.5 以后是 0；紫带 0；序列测试过。
