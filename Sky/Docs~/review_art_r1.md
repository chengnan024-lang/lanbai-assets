# 天空包 · 美术审稿 R1（独立审稿）

- 对象：`pkg/sky` 分支，`Sky/Docs~/presets/preset_*.png`（7 个预设 × 6 视向）、`Sky/Docs~/starsky_world_equirect.png`、`Sky/SkyPresets.json`
- 依据：`Art/ART_BIBLE.md` §1.3、§1.8、§3.1，第 1/2、3、6、8、8b、9 幕各节，`Art/palettes/`
- 方法：先读圣经、看图，自己在参考图上取样（按 90° 水平视场把像素行换算成仰角，中心列 13×7 像素平均），自己算 CIE Lab 紫占比（h_ab 290–325 且 C\* > 15）和晨的严规则（h 285–330 且 C\* > 12）；最后才读 `README_Sky.md` §8 / §10。
- 说明：HDRI 是 1024×512 缩略图，软是预期内的，下面不因为“软”扣分。APL 只有天、没有车厢和云，和圣经 §2 的整帧 APL 不能直接比；只有在差得离谱或碰到 VR 上限（§1.8：白以外全画面 APL ≤ 150）的时候才算问题。

## 1. overcast_rain_night（第 1、2、11、12 幕）· FAIL（第 1 幕）

**取样**：天顶 `#060B14`（目标 `#070B14`），地平线 `#101927`–`#111928`（目标 `#121A28`），向下 `#111A28`。紫 0%。没有低于 `#04060B` 的大面积，没有纯黑。数值上是这七个里最准的之一。

**阻塞**
- **B1 · 第 1 幕没有镇子的光穹。** 圣经第 1 幕：天空“朝镇 ±25° 的地平线填 `#2A1F1E`（→ `#241E22`，向上 12° 消失）”，镇子在方位约 −70°。预设的 `cubeA` 是不带钠光的 `Sky_Overcast_Night`，左 −90° 视向地平线是 `#0E1624`，冷的，没有任何暖。`_TownGlow` 变体贴图做了（README §5），但没有接进任何预设，也没有参考图，钠光默认在方位 0°，需要转到 −70°。第 1 幕“远处的暖光永远很小”这一条正需要它，而且第 1 幕的第一帧就是用户判断这个世界的地方。
  **修**：拆成两个预设：`overcast_rain_night_act1`（TownGlow 变体，`_RotationA` = −70°，出参考图，左 −90° 视向要量到 `#241E22` 附近、12° 以上回到 `#121A28`）和现在这个（第 2、11、12 幕）。

**小问题**
- m1 · 圣经要求“云底有极低对比的结构（防串流压缩出色块）”。README 说做了 ±7% 的 fBm，但在参考图里拉到满对比也只看到 8 bit 的量化台阶，看不到云的形状：±7% 在这么暗的值上不到 1 个码值。建议把结构加到显示上 ±1.5–2 个码值（仍然“极低对比”），并出一张拉伸对比度的检查图。
- m2 · 拉伸后天窗视向有同心圆台阶、前方有横向台阶。引擎里有 PPv2 dithering，参考图没有；请在参考渲染里也加 ±1 LSB 抖动，免得以后有人照着这张图判断色带。

**陌生人测试**：一张几乎纯色的深蓝黑，像没开灯的夜。（对第 2/11 幕正合适；对第 1 幕少了“远处有人家”的那一点暖。）

## 2. moon_night（第 3 幕）· FAIL

**取样**：天顶 `#08101F`（目标 `#08101F`，完全一致），背月地平线 `#111A30`（目标 `#111B30`），朝月地平线 `#18243F`。月的位置：方位 −12.2°、仰角 +8.3°（目标 −12° / +8°）。紫 0%。

**阻塞**
- **B1 · 月亮读不出来。** 月面中心最亮只有 `#7E98BB`（luma ≈ 147），目标是 `#EAEEF4`（月面不裁切、月海看得见，×T0 1.4 微晕）。光晕也偏暗、偏窄：离月 3° 只有 `#2C3B59`，6° 处 `#1B2742`（目标 6° 光晕 `#5A6A88`），10° 处 `#18243F`（目标月旁 10° 天光 `#26344F`）。现在它是一颗发蓝的模糊星，不是“梦一样大的月”。第 3 幕的最亮点是月（§1.3.1），月和月光之路是整幕的脊柱。按 `_MoonColor`（线性约 2.9）× S3 的 −0.9 EV 推，中心应当接近 `#E0E8F0`，所以要么参考渲染器把 5 px 的盘糊掉了，要么 shader 实际输出不对。
  **修**：在原生分辨率（或 4× 超采样后不缩小）出一张月的特写，证明盘心 `#EAEEF4` ±10、月海可见、盘不裁成白饼；光晕按 6° `#5A6A88` / 10° `#26344F` 调 `_MoonGlow`。
- **B2 · 没有星。** 圣经第 3 幕：3a“其上最亮的约 200 颗星”，3c“只有 mag < 3 的星”。预设里星点增益是 0，也没写第 3 幕的星等截断。天空包自己带了真实星表，这一幕的星应该由它给。
  **修**：预设里加 `_Udon_StarGain`，星等上限 3.0（3a 的灯海段可以放到约 200 颗），亮度比第 9 幕低一档；参考图里合成进去。

**小问题**
- m1 · 拉伸后可以看到月晕向两侧水平拉成扁椭圆，朝月地平线一侧整体偏亮。真实月晕是圆的；“朝月一侧地平线亮”可以有，但不应像一条横带。请把圆形光晕和地平线亮度分成两项。

**陌生人测试**：深蓝的夜空里有一颗模糊的亮点，像隔着雾的路灯或者一颗星，不会认出是月亮。

## 3. dawn（第 6 幕）· PASS（带小问题）

**取样**：天顶（天窗 +85°）`#466AA9`（目标 `#3E64A6`），背日 +15° / +25° `#9AB5D3` / `#9AB8D6`（目标背日 20–40° h_ab 255–275、≥ `#6F8FC0`，满足），太阳方位 +45°、仰角 5.8°（目标 +45° / 3–8°），在车门视向正中。紫 0%，严规则（h 285–330、C\* > 12）0%。地平线水平。最亮点是车门里的太阳，单一。“白上的藍与金”这条脊柱成立，没有粉色天、没有薰衣草。

**阻塞**：无。

**小问题**
- m1 · **金星带等于没有，地影带很弱。** 背日地平线 0° `#ABB2C6`、+3° `#A7B2C8`、+8° `#A1B3CE`：没有任何偏粉的一层，`#CFB7B7` 完全看不到；地影带只是一条细灰线。圣经要的是“可见的地影带 + 很淡的金星带”。README §8.1 说加了两条带、效果是“很淡的那一种”，实际是看不见。
  **修**：Band1（地影带）在 0–3° 拉到 `#8C98B8`，Band2（金星带）在 4–10° 拉到 `#CFB7B7`，到背日视向能量出 ΔC\* ≥ 5 为止；或者换圣经候选里本身就有这两条带的 HDRI（`qwantani_sunrise_puresky` 等）。
- m2 · 天顶是“靶心”：天窗视向从 +62° 的 `#9DB4CF` 到 +85° 的 `#466AA9`，L\* 在 20° 内掉了约 30，`_TintElevation` 的 (1, 50, 94.5) 把乘色压在头顶一小块，看起来是一块深蓝斑，不是一整片“干净的藍”。天窗是晨的徽记（§6 节拍 F0s），建议把乘色的过渡放宽，让 +55° 以上就进入 `#5B7ED7`–`#3E64A6` 一带。
- m3 · 日侧太阳周围约 6° 被推到 `#FEFEFD`（车门视向 +3°–+8°），大于 0.9° 的日盘很多。面积不到 2%，不算违反 §1.3.5，但圣经“天空裁切（日盘除外）”要避免。请确认这是 bloom 而不是天空本身 >1；如果是天空，降低 `_ClampA` 附近的日周增益。日侧地平线目标 `#F2C79A`，现在紧贴太阳是 `#FEE9A0`，偏黄偏亮。
- m4 · 地平线以下是一片桃棕到灰粉（前方 −8° `#B68C79`，向下 −35° `#918589`），不是圣经写的“地平线色到天底 `#6F8FA8` 的雾渐变”。C\* 低，没触紫的线，第 6 幕里大部分被云原和后来的海盖住，所以只记小问题。但它读起来正是圣经说要避免的“发褐 / 发灰”。建议下半球从 −2° 起就往 `#8C98B8` → `#6F8FA8` 走。
- m5 · 只有天的 APL 已经 163–177（地平线视向）。圣经 F0s 的整帧目标是 110，§1.8 的 VR 上限是 150。车厢框（比天暗 1.5–2 档）能不能把整帧压回 110，要在 Unity 里用正前方截图确认；如果压不回去，宁可降天的曝光，也不要让车厢变亮。

**陌生人测试**：一张柔焦的清晨日出，太阳低低地挂在右边的暖霾上，头顶是蓝天。（对。）

## 4. dusk_8i（第 8 幕 8-i）· FAIL

**取样**：天顶 `#3D4A7E`（目标 `#3D4A80`），中天背后 / 左侧 +25° `#868EB4` / `#8B95B9`（目标 `#808AB2`），太阳方位 0°、仰角 +0.5°，在前方正中。紫 0%。地平线水平，日线是唯一最亮的地方。天上半部分的数值是对的（8-i 时大部分被海之天花盖住，只露出天缝）。

**阻塞**
- **B1 · 地平线以下是一片暗红泥色，不是“暮色的天”。** 前方 −3° `#C5624E`、−8° `#B45B50`、−15° `#A55A56`、−25° `#8E595D`，向下 −35° `#7A545E`，背后 −15° `#74788B`。前方整个下半幅是饱和的砖红 / 栗色，向下变成泥紫红。8-i 的论点之帧是“头顶是海，下面是暮色的天”，下半球恰恰是这一刻画面的一半，而且海之天花的反射（`ReflCube_DuskLower`）反的也是它，近地平的玫瑰金镜带会把这片泥红再映一遍。圣经第 8 幕“暖只在光里，阴影里只有靛”，“阴影发暖”要避免；另一片天的天底目标是 `#2E3C66`。README §10 说这里是“灰紫的雾渐变，被下方的云卡盖住”，我量到的不是灰紫，而是红；云卡也只有 ≤ 30 张，盖不住半个球。
  **修**：8-i 的下半球不要用 HDRI 的地平线乘色往下延伸。从 0° 的日带 `#F2A56B` 起，−3° 以下尽快转到玫瑰 `#E7A0A0` → 靛灰 `#808AB2` → 天底 `#2E3C66`（或者 8-i 直接用 `_OtherSky` 的 0.5–0.7 当下半球）；`_HorizonTintA` 的红（0.31, 0.07, 0.056）只作用在 ±2° 以内。

**小问题**
- m1 · 天缝目标 `#F2A56B`，前方 +3° 是 `#FECE71`，偏黄、偏亮，更像正午的日晕而不是琥珀的缝。
- m2 · 背日的玫瑰带中心在 −3°（`#CB99A1`），横跨地平线压在下面。金星带应当浮在地平线上方 3–10°、下面是暗一点的地影；现在读起来像地平线上画了一条粉色横杠，上沿还有一条偏硬的分界。
- m3 · 只有天的前方 APL 156。8-i 有天花遮挡，不能直接比，但第 8 幕整帧目标是 76–80，请用 Unity 截图确认。

**陌生人测试**：海面或沙漠上空的粉橙色日落，地平线以下是一大片暗红的地面。

## 5. dusk_8ii（第 8 幕 8-ii · 另一片天）· FAIL

**取样**：天的上半部分同 8-i。下半球按 (−x, −y, z) 取 HDRI，×0.82，染 (0.92, 0.95, 1.05)。我自己量的紫占比：**向下 −35° 视向 2.7%**（整格，包括标签区）/ 3.1%（去掉标签行），作者量 1.9%。

**阻塞**
- **B1 · 读成“天空之镜 / 乌尤尼”，正是圣经点名要避免的东西。** 绕前方轴转 180° 在太阳方向上等于左右镜像：太阳的日晕本身左右对称，所以前方上下几乎一模一样（+8° `#FDC7AA` 对 −8° `#F1B4A1`，+15° `#F2D5CF` 对 −15° `#E5C7C8`），向下 −35° 就是向上 35° × 0.82。接缝处还有一条比上下都暗的红线（车门视向 0° `#CA6A53`，±3° 是 `#E6A378` / `#EBB28F`；左 −90° 视向是一条细而硬的暗红地平线），读起来就是一个水面的边。圣经第 8 幕：“任何地方都没有表面”“没有人说得出‘那是镜子’”；要避免“天空之镜（任何表面、任何波纹、完全对称的倒影云）”。参考图里还没有云卡，但云卡解决不了日晕本身的镜像。
  **修**：（a）下半球的采样方向再绕竖轴转一个角度（比如 25–40°），或者在下半球用另一张 HDRI / 另一段方位，让日侧的渐变上下不对称；（b）接缝处的颜色取上下两边的最亮者，而不是让地平线乘色的暗红在两边各出现一次：接缝应该读成“一条燃烧的光线”，不是“一条暗的边”；（c）下半球的日晕宽度和亮度跟上半球故意不同（比如更窄、更琥珀）。
- **B2 · 天顶是一个带边的蓝盖子，下半球又镜出一个。** `_TintElevation` = (4.47, 36.09, 46.09)：乘色在 36°–46° 之间切换。前方 +7° 到 +27° L\* 一直在 84–88，到 +41° 掉到 58，再往上只缓慢降到 32：一个 10° 宽的陡坡，天窗视向读成一块边缘清楚的蓝圆盘，向下 −35° 视向底部也有一块同样的圆盘。圣经第 8 幕“天花的硬边（读成一个盖子）”要避免，8-ii 的要点又是“任何地方都没有表面”。
  **修**：乘色过渡至少放宽到 30° 以上（比如 10° → 60°），按 sin(仰角) 做 smoothstep；验收是任何视向里相邻 5° 的 L\* 差 ≤ 6。
- **B3 · 紫超线。** 向下 −35° 视向 2.7%（> 2%，§1.3.4），紫的像素正是下半球那块镜出来的蓝盘（平均 RGB 约 (77, 89, 150)）。作者自己量 1.9%，“贴着 2% 的线”，也就是说没有余量：换一个裁法、换一台头显就超。
  **修**：`_OtherTint` 的蓝通道从 1.05 降到 1.0（或者干脆不染），或者让紫护栏对下半球也生效；目标 ≤ 1%，和圣经 S8 测试帧的 0.8% 一个量级。
- **B4 · 太亮，碰 VR 上限。** 只有天的前方 APL 188、车门视向 172。8-ii 时车顶和上墙已经没了，前方几乎全是天，所以整帧会很接近这个值：高于 §1.8 的 VR 上限 150，比圣经 8-ii 的目标 90 高约 1 EV。前方上半部分是一片近白的粉（+25° `#DFD4E0`，L\* 86；圣经中天 `#808AB2` 是 L\* 58），下半部分又镜一遍，整幅变成粉彩的雾。第 8 幕本该是“全片最多的颜色”，现在反而是最淡的一张。
  **修**：日侧中天压到 L\* 65–70 以下（`_MidTintA` 在日侧方位减弱），下半球 ×0.82 不够，日侧再降 0.3–0.5 EV；在 Unity 里正前方截图验 APL ≈ 90、VR ≤ 150。

**陌生人测试**：盐湖“天空之镜”上的粉色日落。

## 6. blue_hour（第 8b · 蓝时）· FAIL（轻）

**取样**：地平线 0° `#647DAA`–`#6881AC`（目标 `#6F86B0`），蓝带 +15° `#3F5B91`（目标 `#2E4F8A`），天顶 `#15213E`（目标 `#16223F`），向下 −60° `#122A56`（另一片天的天底目标 `#1A2A4E`）。紫 0%。没有暖、没有紫，这一点做得干净。“天空里写的第一个蓝白 `#2E4F8A`”基本到位。

**阻塞**
- **B1 · 蓝带做成了一条比上下都暗的条。** 前方 +8° `#466296`、+15° `#3F5B91`，然后 +25° 又亮回 `#516893`，再往上才降到天顶。L\* 在 +15° 到 +25° 之间回升约 5：亮度不单调。色板 `Palette_08b` 的顺序是天顶 → 最纯的蓝 → 地平线，是一条单调的渐变，“最纯”说的是彩度，不是暗。现在这条暗带是画面里最显眼的东西，读起来像一层低云或者一条带子，而不是天色本身。
  **修**：Band1 只加彩度、不压亮度，让 L\* 从地平线到天顶单调下降，蓝带在 +10°–+20° 达到最大 C\*（`#2E4F8A` 的 C\* 37），+25° 不得比 +15° 亮。

**小问题**
- m1 · 圣经：蓝时里“第一批星（`#E8EEF8`，十几颗）在天顶出现——正是宫殿的灯最后散去的地方”。预设和参考图里没有。这是母题链（灯 → 星）的一环，请在预设里写上星点（最亮的十几颗、天顶）并合成进参考图。
- m2 · 向下 −60° `#122A56` 比目标 `#1A2A4E` 更饱和、更偏蓝，彩度高了约 10。可以接受，但和上方天顶 `#15213E` 放在一起，下面比上面更“电”，建议收一点。

**陌生人测试**：傍晚阴天的蓝，地平线上方横着一条暗色的云带。

## 7. star_sea（第 9 幕）与 `starsky_world_equirect.png` · FAIL

**取样**：星空底 `#08112B`（目标 `#08112A`，完全一致），银心暖尘最亮约 `#B8A99D`（目标 `#C8B79A`），银河漫射最亮约 `#5E7191`（目标 `#6F82A0`）。紫 0%。银心位置：星图上约方位 −31°、仰角 +16°（目标 −30° / +12°；`StarSky.json` 写的是 −30 / +12，星图标记略偏高，可能是预览点放大造成的）；银河从左前方拱过天顶到右后方，地平线以下是同一片星空的另一半，不是镜像，这些都对。

**阻塞**
- **B1 · 预设参考图里没有一颗星，银河辉光读成烟。** 六个视向里没有任何高出背景的点（车门视向最大 luma 27、中位 23）。剩下的只有辉光：边缘是一团一团的棉絮，内部一片均匀的灰蓝，看起来像夜里飘着的烟或者云。第 9 幕最重要的一帧（F13 的“一瞬”）是“满天的星一下子都在，一整圈由星本身画出来”，这份参考图完全不能用来判断它。
  **修**：参考图必须把星点（`StarPoints`，FWHM 1.4 px，最亮 50 颗 ×4）合成进去，按 F13 + 4.2 秒（g = 1）出六个视向；再出一张“只有星点、g = 0”的 F13 那一帧。
- **B2 · 银河不是由星画出来的，辉光也不是圣经指定的来源。** 圣经第 9 幕：星和辉光都来自 NASA Deep Star Maps（“去星后的 NASA 立方图”），“银河带内星的密度约为带外的 4.7 倍”，并且要避免“NASA 图以外的星云颜色”。实际用的是 BSC5 + Hipparcos + Vieira 银河轮廓表，带内外密度比 1.67（我在星图上粗测 1.5–1.7，一致）。后果在星图上很清楚：带外两块大暗区里的星和带内差不多一样密；辉光是轮廓表的分级外形，带外是一整块平的 `#0D0F23`，边界是圆滑的大椭圆，两侧银河的亮度也差不多（银心一侧带中约 luma 85–105，反银心一侧约 70–78，真实天空反银心要暗得多），大暗带（Great Rift）基本没有。
  **修**：（a）辉光换成真实的银河照片源（NASA SVS Deep Star Maps；连不上就请本地下载后推到 `FromLocal/`；或者用授权可用的全天银河全景，比如 ESO 的 CC BY 4.0 全景，记得署名），去星后作 `StarSky_Glow`；（b）如果坚持用星表，就把 Hipparcos 的暗星（6.5–9 等）作为极小、极暗的点也放进星点网格，让带内密度真正上去；（c）辉光沿带的亮度按真实分布：人马 / 天鹅亮，反银心暗，Great Rift 看得见。

**小问题**
- m1 · 银河漫射最亮处 `#5E7191`，比目标 `#6F82A0` 暗约 0.3 EV。
- m2 · 星图里的预览点放大了（已说明），但仍能看出星色几乎全白、少数偏黄。B−V 黑体色向白收 45% 可以，但最亮的几十颗应当能看出冷暖（参宿四、心宿二），否则星海只有一种白。

**陌生人测试**：深蓝的夜空里飘着几团灰白的烟，左上角有一块米黄的光斑。（星图本身：一张星空贴图，两条竖的银河带夹着两个大的暗椭圆。）

## 8. 跨预设的共性问题

- **参考图漏掉了每一幕的“点”**：第 3 幕的星、蓝时的第一批星、第 9 幕的全部星点都不在图里，第 3 幕的月盘也读不出来。天空包交付的是“天”，而这几幕天上最重要的就是这些点。下一轮的参考图请把它们都合成进去，并且给点光源（月盘、日盘）出原生分辨率的特写。
- **乘色在仰角上切得太陡**：晨的天顶靶心、暮的蓝盖子都是同一个原因（`_TintElevation` 的过渡区间太窄）。建议在 `Lanbai/Sky` 里统一用 sin(仰角) 上的宽 smoothstep，并在 `make_presets.py` 里加一项自动检查：任何视向相邻 5° 的 L\* 差 ≤ 6（日盘 ±3° 除外）。
- **紫的余量**：作者和我在 8-ii 向下视向上量出 1.9% 和 2.7%，说明结果对裁法敏感。阈值是 2% 的时候，交付值应该在 1% 以下。

## 9. 对 README §8（作者声明的出入）的意见

（以上判断都在读 README 之前做完，下面是读完之后的意见。）

1. **地平线带（地影带 + 金星带）**：**手段接受，结果不接受。** 加两条可调的带是合理的，但现在背日视向量不出任何粉色（见晨 m1）。要么把带调到看得见，要么换一张本身就有这两条带的 HDRI。另外，选的 HDRI 本身不满足圣经的 HDRI 标准（“背日地平线上有可见的地影带 + 很淡的金星带”），这一点应该先报给总导演，而不是只在 README 里说一句。
2. **紫色护栏**：**接受手段，但不够。** 上半球的护栏有效，下半球（`_OtherSky`）的染色把紫又带回来，8-ii 向下视向我量到 2.7%。见 8-ii B3。
3. **背日 45° 只到 `#9FBDDB`（目标 `#AFC4E0`）**：**接受。** 差约 3 个 L\*，色相对，属于 HDRI 本身的限制。
4. **星数 8 404 / 带内外密度 1.67 / 银河辉光不用 NASA 图**：**不接受。** 星数接受；“6.5 等的真实星表就是这个比例”这句话本身没错，但圣经要的是“一整圈由星本身画出来”，而且明确指定了 NASA 图和“NASA 图以外的星云颜色要避免”。换数据源是改圣经的事，需要总导演签字，不能由实现方自行决定。现在的结果（见星海 B2）也证明这个替换在画面上有代价。README §10 自己也承认“近看 Great Rift 的细节比 NASA 图少”，这正是问题所在。
5. **暮的日盘完全程序化**：**接受。** 圣经也是这么写的。

README §10 里另外两条自认的弱点：
- “晨的地平线以下偏灰，被云原盖住”：**接受为小问题**（晨 m4）。
- “暮的地平线以下在 8-i 是灰紫的雾渐变，被下方的云卡盖住”：**不接受。** 我量到的是砖红到泥紫红，不是灰紫；云卡也盖不住半个球；天花的反射还会把它再映一遍。见 8-i B1。
