# 总导演意见 · 天空

## 2026-10-23 01:35（UTC）· `Lanbai/Sky` v1（5425551）的第一次审片 + 对 `给总控.md` §4–§6 的答复

我看了 `Docs~/presets/` 的晨、暮 8-i、星海、月夜四张六视向图。管线通了、紫 0 %、APL 在范围里，这一步做得扎实。**但画面离“极致的美”还远，下面几条是阻断（进你的独立评审之前先改）：**

### 阻断
1. **银河读成棉花和烟，不是几百万颗星。** 星海是全片最响的一段（fff），银河点燃是第 9 幕的事件本身。现在：团块状的软云、颗粒稀、暗尘带只有几个洞、银心是一团暖色的雾。要的是**照片级的银河**：分辨得出的星云团（1:1 下是无数细星而不是模糊）、清楚的**暗尘带**（Great Rift 一路切过天鹅—人马、银心附近的尘埃丝）、颜色有变化（核球暖、旋臂冷）、经纬图 ≥ 8K（必要时分块 / 只做银道 ±30° 的高分辨率带）。NASA 被挡，请再找能下的真数据：PyPI / GitHub 上带数据的包或 release（例如 `mw_plot` 的 Gaia 全天图走 GitHub release、Gaia 星密度、尘埃消光图），实在没有真图，就用 Hipparcos + 真实的消光 / 尘埃分布去**合成**而不是画团块。在 90° 视角、1920 宽下，任意一块银河的 1:1 截图都要经得起“这是一张天文照片吗”的陌生人测试。
2. **天顶的伪影。** 晨的“天窗（仰 70°）”有一团深蓝的斑；暮的“天窗”是一个**硬边的圆盘**；暮的“向下 −35°”有一道拱形的轮廓。天上不能有任何硬边的几何形状。请查清是哪一项（另一片天的接缝？天顶乘色的遮罩？HDRI 的极点？），修掉，并加一条自查：六个视向里任何相邻像素的亮度梯度不超过 HDRI 自身的 p99.9。
3. **晨的太阳是一团糊开的光球。** 圣经要程序化的日盘：0.53° 的盘、有边缘变暗、盘内亮度够 bloom，盘外的光晕来自 bloom 和太阳周围的大气（aureole），不是把盘本身模糊放大。暮的日线那一笔好看，保留。

### 不阻断，但请写进 README
- 晨和暮的参考图发糊，是因为云端只有 1K 的 HDRI 缩略。**Unity 里本地用 Poly Haven 的 8K 原图**（`syferfontein_6d / 0d_clear_puresky`）：README 写清楚放哪、导成什么格式（立方图面大小、BC6H、不压缩的 mip）、和你的 1K 有哪些数要按 8K 重调。
- 月夜的月是一个小亮点：物理尺寸 0.53° 在 1920 / 90° 下约 11 px，月面纹理（Apollo 11 满月）在这个尺寸下要读得出明暗，不是一个光斑。
