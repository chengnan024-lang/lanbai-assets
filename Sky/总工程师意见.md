## 一、必须改

### 0. 总导演问的：天空盒换不换材质（技术定论，优先于下面第 3、4 条里关于 `setSkybox` 的写法）

**定论：全片一个天空盒材质（`Lanbai/Sky` 的一个实例），预设之间的差别全部走全局量；`RenderSettings.skybox` 只在搭建时设一次，运行时不写。**
- `RenderSettings.skybox` 的 setter 在 Udon 里大概率是暴露的（VRChat 的换天空盒小工具就这么用），但我在这里核不了白名单——这不是决定性的。决定性的是：
  1. **换材质没法交叉淡化**：两个材质之间只能在一帧里切，圣经 §1.6 要 2–6 秒交叉；除了遮挡，任何一次换材质都是一跳（第 3 条里 t = 1 那一帧就是）。
  2. **换天空盒不会更新环境光 / 反射**：Unity 的环境光（Skybox 模式）和默认反射探针要 `DynamicGI.UpdateEnvironment()` 才跟着变，那个在 Udon 里不能用；我们全片用 Trilight、反射用烘好的 `_Udon_ReflCube`，所以本来也不该依赖天空盒去照东西——一个材质就够了。
  3. **一份材质 = 一组贴图常驻**：4096×2048 的银河辉光、两张阴天 HDR、月盘都挂在同一个材质上，按全局量选层；不用担心“换材质那一帧才上传贴图”的卡顿。
- 怎么改：`Lanbai_Sky.shader` 已经是分层的（`LanbaiSkyLayers.cginc`），把“哪一层开、各层的增益 / 颜色”全部做成 `_Udon_` 全局量（大部分已经是：`_Udon_SkyBlend`、`_Udon_StarGain`、`_Udon_GalaxyGain`、日 / 月……），材质属性只当“没设全局量时的默认值”。7 个预设 = 7 组全局量的值，`ApplyBlend` 在两组值之间插值就是交叉淡化。`setSkybox` 字段删掉（或者留着只给测试场景用、默认 false），`LanbaiSkyBuild` 在搭建时把这一个材质设成场景的天空盒。
- 第 1、2 幕的阴天夜和第 6 幕的晨，如果需要的贴图层不同，也放进同一个材质的不同贴图槽，按 `_Udon_SkyBlend` 选——显存是一样的（贴图本来就要常驻，因为全片只有遮挡下才能换东西）。

### 3. `ApplyBlend` 只遍历自己的名字，"0.5 处跳变"永远不会发生，t=1 时还当众换材质（major）

  1. 对两边名字的并集做混合。第一次调用时缓存双向索引（缺的记 -1），顺便去掉每帧的字符串比较。只有一边有的名字：rgb/x 插值到 0，w 保持不变，到 t=1 再写成目标侧的值或 0。float 同理。

  4. 把第 6–7 行的注释改成实际行为。

### 6. 月盘固定采样 mip 0，缩小约 40 倍，在 VR 里会闪、边缘会爬（major）
- **文件:行**：`Sky/Shaders/LanbaiSkyLayers.cginc:159`（`tex2Dlod(_MoonTex, float4(uv, 0.0, 0.0))`）。
- **证据**：
  - 1.2° 的月盘在眼缓冲里约 20–24 px，贴图是 1024 px，约 45–50 texel/px，相当于 LOD 5.5。

- **怎么改**：在 `sampler2D _MoonTex;` 旁边声明 `float4 _MoonTex_TexelSize;`，把采样换成：
  ```
  float lod = log2(max(_MoonTex_TexelSize.z * k * LanbaiPixelAngle(), 1e-4));
  float4 t = tex2Dlod(_MoonTex, float4(uv, 0.0, max(lod, 0.0)));
  ```
  采样在动态分支里，导数不可靠，所以必须显式给 LOD。可选：导入最大尺寸降到 256，省掉 2.3 MB 的 PNG；显式 LOD 照样保留。

### 7. 日盘和日线的软边窄于一个 VR 像素，HDR 边缘会走样、会爬（major）
- **文件:行**：`Sky/Shaders/LanbaiSkyLayers.cginc:139`；`SkyPresets.json` 里 dawn/dusk_8i/dusk_8ii 的 `_SunShape.y = 0.04`。
- **证据**：
  - 0.04° 的软边只有约 0.6–0.8 个像素。
  - 日盘峰值 5.86–6.68 linear，覆盖率超过约 0.17 就已经剪成白，实际可见的边只有 0.1–0.15 px。

  - 第 8 幕的日线是一条很长、接近水平的边，歪头时会出明显的阶梯爬行。
- **怎么改**：
  ```
  float pxDeg = degrees(LanbaiPixelAngle());
  float soft  = max(_SunShape.y, 2.0 * pxDeg);
  float cov   = smoothstep(radius + 0.5*soft, radius - 0.5*soft, a);
  float peak  = max(max(_SunColor.r,_SunColor.g),_SunColor.b) * gain;
  float edge  = (peak > 1.0) ? pow(cov, log2(peak) + 1.0) : cov;
  ```
  可选：把 `make_presets.py` 里的 `_SunShape.y` 提到约 0.10°。

## 二、建议
