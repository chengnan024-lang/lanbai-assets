# 天空 → 总控

## 1. 要登记的新全局量（`Common/UdonGlobals.md`）

用法见 `Sky/README_Fog接口.md` §3。都由“当前幕的驱动”写（第 6、8、9 幕是天空的驱动），读的是 `LanbaiSky.cginc` / `LanbaiFog.cginc`（也就是所有走 `LanbaiFog` 的 shader）和 `Lanbai/Sky`。

| 全局量 | 类型 / 含义 |
|---|---|
| `_Udon_NadirColor` | float4：rgb 天底色（线性，雾色模型 B）；a > 0 = 设了 |
| `_Udon_FogShape` | float4：x 满的仰角、y 没了的仰角（> 0 = 设了）、z 幂、w 背后带增益 |
| `_Udon_FogBelow` | float4：x 起的仰角（< 0 = 设了）、y 止的仰角、z 最暗系数 / 天底过渡的幂、w 去饱和 |
| `_Udon_FogCube` | 贴图（立方图）：预调色、预模糊的天，雾色用 |
| `_Udon_FogCubeParams` | float4：x 权重（> 0 = 用）、y mip、z 取样最高仰角、w 曝光乘数 |
| `_Udon_FogBase` | float4：x 高度衰减的基准高度；w > 0 = 设了 |

预留里的 `_Udon_HorizonColor`（a 用来选模型：1 光带 / 2 渐变）、`_Udon_ZenithColor`、`_Udon_SunDir`、`_Udon_SunDisc`（x 增益、y 半径度、z 软边度）现在开始用。

## 2. 门（私密对话）需要知道的两件事

1. **include 顺序**：`Gate/Shaders/LanbaiGateSky.cginc` 里的 `_Udon_FogBand*`、`_Udon_TearPos/TearH`、`_Udon_MoonDir/MoonDisc` 没有 `#ifndef` 保护。同一个 shader 里两个都要用时，**必须先 include `LanbaiGateSky.cginc`，再 include `LanbaiFog.cginc`**；反过来会重复声明、编译失败（我用测试 shader 验证过）。
2. **`Lanbai_TentacleSway.shader` 第 306 行那句注释掉的 `#include "LanbaiFog.cginc"` 不要照原样打开**：它在 GateSky 之前，而且 TentacleSway 自己声明了 `_FogCap`、`_Udon_FogDensity`，会重复。第 4 幕里 `LanbaiBand` 和 `LanbaiHorizon` 逐方向相等（最大差 1.2e-7），触手维持现状就是对的。如果她以后要接，就把那行挪到 GateSky 之后，并在 include 前 `#define LANBAI_FOG_OWN_UNIFORMS`（并把 `_FogCap`、`_Udon_FogDensity` 的声明挪到 include 之前）。她的云卡 shader（`GateClouds/`）照 `README_Fog接口.md` §1 接就行。
3. **第 4 幕里 `_Udon_FogBandColor` 要有人写**（a > 0），否则走 `LanbaiFog` 的新 shader（门的云卡、海……）在第 4 幕会用 `RenderSettings.fogColor`（`#505466` 的平均值）而不是光带。登记表里写的是“第 4 幕 = 门的驱动”，请她确认会写；写 `LANBAI_GATE_NEAR` 那个值（0.1085, 0.1130, 0.1641, 1）即可。

NASA SVS（星图、CGI Moon Kit）、Poly Haven、CDS 都连不上；GitHub raw 和 PyPI 可以。星表我用 GitHub 上的 Yale Bright Star Catalog（公有领域）/ HYG（CC BY-SA 4.0），来源和许可写进 `Sky/README`。银河辉光和月面贴图如果找不到可下载的 NASA 原图，我会用星表自己生成（写明），等本地能下 NASA 图时再换。
