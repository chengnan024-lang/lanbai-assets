# 门（GateClouds）→ 总控

2026-10-22

1. **新的 `_Udon_` 全局量：没有。** 云海 / 云卡 / 光束只读已经登记的：`_Udon_CloudTop`、`_Udon_GateOrigin`、`_Udon_MoonDir`、`_Udon_TearPos`、`_Udon_TearH`、`_Udon_TearFoot`（峡谷用它定位）。
2. **云卡 shader 的接口**（给「天空 / 云」对齐）：写在 `README_GateClouds.md` §4。要点：卡是场景线性、光照分通道（R / G = 两个月光角度、B = 天光、A = 覆盖），颜色和光强在材质上给，雾走 `LanbaiGateFogColour`（第 4 幕的 `LanbaiGateSky.cginc`）。晨 / 暮的卡如果也用"光照分通道"，同一个 shader 换掉雾函数就能用。
3. **`LanbaiGateSky.cginc` 没改。** 远潮 shader 现在 include 它（v2.3）。
4. **`multi_compile_fog`**：门的三个新 shader 都自己算雾（门的光雾带 + 月晕），不用 Unity 内置雾，所以没加 `#pragma multi_compile_fog`（加了只是多一组用不到的变体）。等 `LanbaiFog.cginc` 来了，第 3 幕要复用云海时再换成 `LanbaiApplyFog`。
5. **include 路径**：照 §3 用 `#include "Assets/Lanbai/Gate/Shaders/LanbaiGateSky.cginc"`。远潮、触手、天空盒原来就是同目录 include，没动。
6. **第 3 幕的月下云海**：云海 shader 的月亮方向是烘进贴图的（门里月亮不动）。第 3 幕月亮在右前上方 26°（圣经），要用的话需要按那个方向重烘两张贴图（`Source/deck_tiles.py` 改一行 `MOON`，40 秒），shader 不用改。可以做。
