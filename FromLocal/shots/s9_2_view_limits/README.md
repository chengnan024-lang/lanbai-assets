# §9 第 2 条 · 主座位的视窗极限（v1 车，2026-09-30）

**先说结论：** 现在的车是占位的 v1（门在车身中间、主座位离挡风玻璃约 3 m、没有天窗）。圣经 §4.1 / §6 假设的构图，大部分在 v1 里做不到：挡风玻璃只有约 30° × 19°；门洞被折起来的门扇挡住一大半；没有天窗。车用哪一辆，小楠还在定（买现成的，或者云端做），这里的数只描述 v1。

## 怎么量的
- Play 里、站牌状态（门开着），在 Unity 里从眼睛位置按 **0.5° 网格**打射线，只打车上的网格（临时碰撞体副本，背面也算），记下第一个碰到的是哪块玻璃；没碰到车 = 从开着的门洞出去了。
- 眼睛 = 座垫所在地板 + 1.15 m（圣经 §4.1）。车在原点、车头朝 +z。方位 0 = 车头、+ = 右（车门一侧）；仰角 0 = 水平。
- 主座位 = v1 的 `SeatR0`（右侧第一排、车门后面），眼睛 (0.70, 1.77, 0.20)，离路面 1.77 m（圣经是 2.1 m：v1 地板只有 0.62 m）。
- 后排 = v1 左侧第 3 排靠窗 `SeatL2_-0.72`，眼睛 (−0.72, 1.77, −1.44)。
- 图：`view_limits_v1.png`（上：主座位，下：后排；虚线框 = 圣经假设的窗，圆点 = 圣经里的月、日、诗句等目标）。截图：`hero_*_grid.jpg`、`rearL2_fwd_grid.jpg`（1920×1080、水平 FOV 90°、后处理开，叠了方位 / 仰角网格，每 10° 一条）。

## 圣经里的目标落在哪（主座位）
- 在挡风玻璃里：月（−12°/+8°）、暮日（0°/+0.5°）、唱词 4b（0°/−6°）、天问 / 庄子 11（0°/+8°）、河伯（−25°/+6°，贴着左边框）。
- **看不到**：裂口顶 U7（0°/+18°，挡风玻璃上沿只到 +10.5°）、银心（−30°/+12°）、收音机（−20°/−12°；v1 的收音机在仪表台上，约 −25°/−8°）、“我从天空坠入深海”（−15°/−12°，在挡风玻璃下沿以下）、里尔克（+20°/+3°，在门扇上）。

- 在自己的侧窗里：庄子 8-ii（+35°/0°）、李白 3/12（+50°/−9°）、济慈（+50°/−14°）。

## 给定车的人参考（不是 v1）
我停掉的 v2 原型（考斯特式前门：门紧挨挡风玻璃、主座位就在门后、踏步上方有天窗）在 Blender 里量过同样的数，只作参考：挡风玻璃 −42° … +5° / −14.5° … +16°；门洞 +12° … +22.5°；天窗 −55° … +7° / +42° … +68.5°。**靠窗座离侧壁只有约 0.3 m，所以哪怕门紧挨着座位，门在主座位看来也只有 +12° … +25° 左右；圣经假设的 +30° … +65° 要眼睛离门的平面约 0.6 m 才做得到。** 晨日、站牌灯如果要框在门里，方位大概要放在 +15° … +20°。
