# §9 第 6 条 · 晨 / 暮 HDRI 候选（Poly Haven，CC0）

本地会话量的（2026-09-30 中午）。28 张 Poly Haven "pure sky" 按圣经 §6·6 / §6·8 的标准量了一遍：
- `contact_all.png`：全部 28 张的上半球缩略图（红圈 = 太阳，青线 = 背日 20–40°），标题行是量出来的数。
- `views_dawn.png`、`views_dusk.png`：前 6 名各三个方向（朝太阳 / 背日 / 侧 90°），水平 FOV 90°。
- `hdri_measure.json`：数据；`analyze_hdri.py`：怎么量的（太阳 = 最亮点；背日 20–40° 的 CIE Lab h_ab 与 C\*；背日地平线 0–6°、8–20°；天顶；动态范围 = 最亮 / 天空中位数）。
- `hdr/`：候选的 **1024×512 `.hdr`**（Poly Haven 的 1k 版，线性，没改过），给云卡 v2 重打光和量背日天空用。原图全部 ≥ 16K。
