# 星海大面积白闪：本地复现、隔离与最小修复

2026-10-25，FullPreview，Unity 2022.3.22f1 / DX11 / ClientSim。只向仓库回传 FromLocal 报告与审阅补丁；工程修改已先备份。

## 已确定并修复的一项故障

旧星海占位 SeaA/SeaB 的旅程颜色、镜面模式、淡出等值原来写入 Renderer 的 MaterialPropertyBlock；VRC 镜面也使用这一个属性块。启用镜面时，诊断读到 `_Mirror=0`、`_SkyTop.r=0`（该属性块没有保留旅程值），画面反复退回材质的浅蓝白天默认外观。整个测试区间禁用镜面后，两值稳定为 `1` 和 `0.023529`，大面积浅蓝白闪消失。这是运行时实测，不是单凭镜面报错猜测。

修复仅改变 `LB_Journey.SetSeaLook` 的数据归属：SeaA/SeaB 各缓存一份运行时材质实例，旅程外观写该实例，镜面继续管理其反射属性块。未改 SDK，未关闭最终镜面，未改共享材质资产、镜子穿越时刻或公交消散时序。审阅补丁为 `LB_Journey.patch`。

另修正诊断器：`_Udon_StarGain` 用 Vector 读取。之前以 GetGlobalFloat 得出“stars=0”的结论无效。

## 对照方法与结果

独立诊断相机在车内固定基点捕获960×540 HDR转LDR序列，约10帧/秒；修复前后匹配的直接跳转测试均有±1.2厘米横向微动，后处理AA=None。镜面、海面、公交与后处理保留，除对应隔离试验外一次只变一个因素。全部原始PNG在本地备份，仓库收录CSV、错误记录、组合图与请求/结果。

| 条件 | 帧数 | 相邻帧平均绝对差的95分位，0–255 | 最大值 |
|---|---:|---:|---:|
| 修复前，1023–1040.93秒，微动 | 177 | 36.94 | 132.11 |
| 隐藏SeaA/SeaB，仅用于定位 | 177 | 2.38 | 8.07 |
| 整段禁用镜面，仅用于定位，微动 | 177 | 8.11 | 30.27 |
| 修复后，1023–1040.92秒，微动，镜面正常启用 | 177 | 8.01 | 30.45 |

同范围同微动下，这个像素差指标95分位下降约78%，最大值下降约77%。它用于证明异常跳亮显著减少，**不是闪烁频率、感知评分、GPU耗时或VR舒适度认证**。镜面穿越本身仍有画面变化，不能以所有像素差为零作为标准。

最明显的异常在第一批穿越的约1032.5、1035.0、1038.1秒；用户原话为“1025秒开始”。没有把用户截图显示的1277秒当成同一时刻。

其他隔离：仅在诊断相机渲染期间关闭镜面仍会继承主相机已经擦掉的属性块，因此最初 `no_mirrors_direct` 并不是完整隔离；已保留其结果并补做整段关闭。禁止反射混合和强制公交不透明均未消除浅蓝白闪，不能据它们归因为公交棋盘消散。隐藏海面消除了大面积跳亮，但最终修复保留海面和镜面。

自然播放入口另从1009秒连续进入测试区间；修复后首次捕获因实时帧耗时仅走到1037.30秒，没有冒称覆盖1041秒。随后从995秒连续进入，实际捕获995.118–1169.955秒、1728帧，覆盖13个镜面穿越，捕获期间0错误。前12次穿越没有再出现原来的浅蓝白天面；本段95分位像素差6.51。**1149.39秒的第13次穿越与进入白段重合，仍有73.47的大跳变，下一轮需单独核对白段交接；不将其默认当作有意的剧情冲击，也不宣称所有转场或所有闪烁已经验收。** 详见 `fix_all_crossings/frames.csv` 及请求结果。

## 不能由本次测试推出的结论

- 当前正式镜面/白段最终包仍缺失，星海继续使用旧海面占位；修复不等于该段最终艺术表现通过。
- 公交屏幕棋盘消散仍存在，近距离边缘/头动细闪仍需独立观察与最终公交方案；没有粗暴删除消散。
- 01:50镜面相机的 Screen position out of view frustum 错误在这些捕获中没有复现，不能宣布全部镜面相机问题已修好。
- 两个 `Lanbai/Sea` 同名Shader仍是已记录问题。现有SeaA/SeaB材质GUID实际引用旧Shader；本次没有把同名直接当根因，也没有删除任何Shader。
- 这是编辑器单目相机和真实Play时钟验证，不是真实头显双眼/多人VRChat验证，也不是全片审美验收。
- 晨景云体/矩形通道、门触手断口、转场、海下内容与树仍待后续处理。本次没有声称它们已经修复。
