# cues.md · 乐句标签的实际秒数（本地实测，2026-09-30）

给云端：U0–U12、F0–F16 在 build 实际播放的两个音频文件里的秒数，以及它们在时间轴上的秒数。机器可读版 `cues.json`；Audacity 标签 `cues_urlicht_audacity.txt` / `cues_finale_audacity.txt`（文件 → 导入 → 标签）；标注图 `cues_urlicht.png` / `cues_finale.png`（灰 = 全曲响度，红 = 分离出的人声）。

## 怎么量的

- 我听不到声音，所以没法像圣经说的那样在 Audacity 里边听边打。做法是：Demucs（htdemucs）把人声从乐队里分出来 → 人声能量的起点（10 ms 精度）定每一句的开头；Whisper（medium）转写德语对上是哪一句；pYIN 音高和 CQT 频谱看旋律和独唱 / 合唱的织体；AudioSet 分类（AST）找长笛、号角、定音鼓；众赞歌的分句看乐队的能量谷。
- **“高”** = 人声或乐队有清楚的起音，误差 ≤ 0.2 s。**“中”** = 事件是对的，边界 ±0.5–1 s。**“低”** = 推断，±2 s。
- 没有人声的几个标签（F1 鸟鸣、F2 最后一声鸟鸣、F15 钟）最不可靠。要是需要更准，小楠可以把 `cues_finale_audacity.txt` 导进 Audacity，听 30–60 s 和 100–127 s 两段，拖一下标签再导出——不做也没关系，现在的值够排第一版。

## 时间轴映射（我这边会照这个实现，t = 出发那一刻为 0）

- t = 0 出发（全房间同步的时刻）→ **3.0 s 收音机调台噪音** → Urlicht 文件从 0 秒开始放：**t = 文件秒 + 3.0**。U0 于是落在 t = 3.9。
- **Urlicht 播到 U12 结尾**（245.64 s，文件里最后一个可闻采样），没有在 U9 剪掉——4c 有完整的 69.1 s。
- U12 → F0 **恰好 3.0 s 数字静音**（投入）。末乐章从文件 11.18 s 开始放（F0 前 0.1 s，0.1 s 淡入，不切号角的起音）：**t = 文件秒 + 240.36**。文件开头 0–11.2 s 是前一段崩塌的余响（就是被静音替换掉的那声尖叫），不播。
- 末乐章播到文件结尾；F16 终和弦在 t = 1149.31，和弦收在 t = 1170.76，文件在 t = 1173.46 结束 → 之后 5 s 白里的数字静音 → 10→11。
- 两个文件的结尾都是被截断的（Urlicht 在 −47 dBFS、末乐章尾巴在 −47 dBFS），不是自然消失。我会在播放时加淡出：Urlicht 243.9–245.64、末乐章 930.6–933.1（文件秒），不改文件，“马勒一个音都没剪”仍然成立。

### F15 的钟

这版录音里单独的钟声我分不出来（onset 检测、频谱、AudioSet 的 Bell / Tubular bells 都没有可靠的信号；钟被乐队和管风琴盖住了）。给镜子吸附用的是 F13–F16 之间 **onset 强度最大的 40 个强拍**（`cues.json` 的 `F13_F16_accents_*`，Audacity 文件里的 `accent`），节拍约 57.4 bpm。如果一定要钟，需要有人按耳朵标。

## 由标签算出来的两个量

- **第 4 幕世界速度 v_g = 2 700 m ÷ (U9 − U6) = 2 700 ÷ 45.75 = 59.02 m/s**（在 45–65 之间）。
- **第 9 幕镜子公比 r = 1.2265**：F16 − F13 = 131.1 s，扣掉点燃 4.2 s + 保持 10 s，Σd = 116.9 s。间隔 2.5、3.07、3.76、4.61、5.66、6.94、8.51、10.44、12.81、15.71、19.27、23.63 秒。
- 第 1 面在文件 792.05（t 1032.41），第 13 面 = F16。吸附到 ±0.8 s 内最近强拍（且保持每个间隔 ≥ 2.5 s）后的 13 次穿越（时间轴 t）：1032.41、1034.91、1037.98、1041.74、1045.82、1052.3、1058.95、1067.46、1077.21、1089.91、1106.41、1125.55、1149.31。
- F12 → F13 = **31.15 s**（≥ 30 s，蓝时的完整计划 6 + 8 + 8 + 8 放得下，不用压缩）。F12 → F16 = 162.2 s（圣经估计约 170 s）。
