# 树的对比：我做的杨树 + 灌木 vs 小楠的 Linluo 树（2026-09-30）

同一个雨夜、同一组机位、同样的 7 个位置（右侧 4 棵、左侧 3 棵，站牌附近 z 14–40 m）。拍的时候把场景里原有的树都藏起来了，只留这 7 棵。
场景里的树**还没换**（还是杨树），等云端定。

| 文件 | 内容 |
|---|---|
| `poplar_*.jpg` | 我做的杨树 `Poplar_A/B/C` + 灌木 `Bush_A/B`（`Lanbai/Foliage` shader：cutout、包裹光照、顶点风） |
| `linluo_*.jpg` | 小楠买的 Linluo 树（`Assets/Tree pack`，**原样的预制体和材质**：Unity Standard，叶子 cutout）。材质没调过，所以夜里偏亮、偏绿——比较的是模型本身 |

机位（Unity 世界坐标，车在原点、车头朝 +z；垂直 FOV 55°，1600×900，后处理开，Night profile）：
- `overview`：(4.6, 1.65, −9) 看向 (4, 5, 30)——站牌后面的右侧路肩，车在左边
- `right`：(3.2, 1.65, 2) 看向 (10, 5, 24)——右侧，站牌旁的钠灯（6.3, 11）照着第一棵
