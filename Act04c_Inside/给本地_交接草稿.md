## 一、拷什么

1. 拷进工程：
   - `Act04c_Inside/` → `Assets/Lanbai/Act04c_Inside/`
   - `Overlay/` → `Assets/Lanbai/Overlay/`
   - `Common/Shaders/` 整个（`LanbaiGlobals.cginc`、`LanbaiFog.cginc`、`LanbaiSky.cginc`、`LanbaiVR.cginc`）→ `Assets/Lanbai/Common/Shaders/`
2. 带 `~` 的文件夹（`Tools~`、`Docs~`）Unity 不导入，拷不拷都行。
3. **项目设置**：Player → Vertex Compression 里**不要勾 TexCoord0–3**（门那条已经要求过）。门内的布把“离撕边多少米 / 沿撕边多少米”存在 UV1，丝线的运动存在 UV1–3，压缩了会全错。
4. 导入设置是 `Act04c_Inside/Editor/LanbaiInsideImport.cs` 自动设的，只管这个文件夹：
   - 网格不压缩、不生成光照 UV、不导材质；
   - 天窗光斑和暖白点的网格 bounds 放大（它们的顶点在 shader 里移动）。

## 二、搭（顺序不能换）

1. **蓝白/Build/Overlay**：建遮罩球 `Lanbai_Overlay`。
2. **蓝白/Build/04c 门内**：建 `Lanbai_Inside`，里面有：
   - `InsideRoot`：8 重光唇；
   - `Inside_BusAnchored`：2.4 km 的穹、暖白点、松散丝线；
   - `LanbaiInsideDriver`；
   - `Skylight_Spot` + `LanbaiSkylightSpot`：第 4 幕 U8 → U9 天窗落到过道上的光斑；
   - `Inside_TestClock (test scene only)`：关着。

   `InsideRoot` 和 `Inside_BusAnchored` **开始都是关的**，由驱动开关。
   Console 应该看到 `[Lanbai 4c] built Lanbai_Inside: N renderers ... Skylight spot: 3 renderers ... Test clock (off)`。
3. **手动接线**（驱动 `LanbaiInsideDriver` 的 Inspector）：
   - `overlay` = 场景里的 `Lanbai_Overlay`；
   - `exposure` = `Lanbai_Grades` 上的 `LanbaiExposure`。测试时勾 `writeExposure`，正式世界里不勾，由 Director 合成；
   - `worldMainLight`：搭建时如果是空的，会按名字自动接上 `Gate_Lights/Moon`。请确认接上了。
4. **月光（D-24）**：全片只有这一盏带阴影的主光。门的驱动在 U9 之前写它；U9 起门内在门和门内两个亮度之间插值写它。

   - 正式世界里：等 `LB_Journey` 把第 4c、5 幕的窗口（177.55 → 252.64）加进 `extSun` 以后再勾。
   - `writeRenderSettings` 同理：测试场景勾，正式世界等加进 `extAtmosphere` 以后再勾。环境光模式要是 **Trilight**。
5. **测试时钟**：把门的 `Gate_TestClock` **关掉**，打开 `Inside_TestClock`。
   - 它从 166 跑到 252.64，按各自的窗口开关、推门、云海、天窗光斑、门内四个驱动；
   - 到头先全部关掉再从头跑，所以也测了“第二次发车”。

6. 以后重跑 **蓝白/Build/04c 门内**：会保留驱动上手动接的引用、`tLichtDial` 和两个 write 开关。重跑完要重新点一次测试时钟的开关（它是新物体）。
