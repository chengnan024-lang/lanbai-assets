# 陌生人测试 r05（640×360，三个互不知情的新会话，各看一张，只给 brief 里那两句提问）

| 图 | 帧 | 他们说的（原话） | 眼睛先落在 | 我的读法 |
|---|---|---|---|---|
| a | 205 正前 | “一块半透明的玻璃或屏幕状平面，上面浮着不规则的裂口和洞形轮廓，安静、神秘、有点孤寂和超现实” | 中央的小发光白点 | “裂口”读到了；材质读成玻璃 / 屏幕，**不是布**。暖白点是落点 ✓ |
| b | 226 侧窗（袖里） | “一片起伏、边缘发亮的半透明**帷幕状**曲面，布满细密的弧形发光线条，冷静、安静、有些科幻” | 右侧亮白、参差起伏的边缘 | 读成帷幕（布）了 ✓；r03 读成岩石 / 冰 |
| c | 240 尾声 | “深海军蓝的空间，一个大的灰蓝色矩形框，中间一根细黑竖线，旁边悬着一个发柔光的小亮点，安静、空旷、孤寂、超现实” | 发光的小亮点 | 暖白点是落点 ✓；“空旷、孤寂”是尾声要的；框是车窗（占位车壳） |

结论：r03 的“岩石 / 冰 / 霜”没有了；袖读成帷幕；正前方的几层仍可能被读成玻璃上的裂口（远处的层很淡、布的纹理在 640 px 下看不出）。见 README §9。
