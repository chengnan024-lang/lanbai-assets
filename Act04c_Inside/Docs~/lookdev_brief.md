# 第 4c 幕 · lookdev 简报（要达到什么、怎么量）

## 要达到的一句话
门里面是暗的。一层层撕开的布在前方错开着退去，每一层的边亮着细细的纤维，一层比一层白、一层比一层淡；暗下来的车厢里收音机的表盘是唯一的暖；最深处一个温暖的白点在等你。（圣经 §6·4c）
陌生人测试要听到的：**“一层一层撕开的布 / 帘子，后面有一点暖光”**——不能是“隧道”“传送门”“洞穴”“花”“冰霜”“毛皮”。
