## 四个视角一致的三件事（r03，四份都判“不通过”）
1. **纤维只有法律亮度的一半，“一层比一层白”读不出来。** 圣经 §6·4c 大气：光唇与纤维本身 luma 200–235。r03 除暖白点外最亮 0.1% 只有 luma 97–123（单像素最高 163），只比身后的雾亮 0.7–1.2 EV；三种纤维色 `#E6E1F2 / #D9DFEE / #C2D8E2` 的最近像素 ΔE2000 在每张图里都是 25–39。色相方向是对的（181 偏一丝紫 → 205 偏青 → 218 偏瓶覗），缺的是“白”。
2. **全曲最响的 LIP8 *Leben*（224.75 → 231，主机位 228 没渲）正前方是一张灰卡加一个点**，和 240 尾声几乎分不出来（226 APL 64.4 / 平均色 `#3E4956`，240 APL 65.2 / `#3F4A56`）。袖只在侧窗 / 车门 / 天窗里读得出；“只有第 8 重框住暖白点”在正前方读不出（出口开口 H 195 m、离车约 85 m，边全在画框外；第 7 重框得几乎一样紧）。另外 VR 视角指出 `layout_solved.json` 的第 8 重是种子 115、偏移 (−44.1, −2.3)、净空 40.2 m，**不是总导演 D-02 批准的种子 107 / (−41, +32) / 43.8 m**，请核对。
3. **APL 提前到顶，尾声没有变亮的弧线**：§2.2 是 179.55 → 248.64 线性 30 → 55。r03：197 = 41.9（目标约 36，+16%）、205 = 50.1（约 39，+28%）、226 = 64.4（约 47，+37%）、240 = 65.2（约 52，+25%）。原因在 DESIGN_4c §3：前方取 s + 250 m 那一区的颜色，约 216 s 以后前方已经是第 8 区的终色。
另外 VR 视角：车厢里没有收音机表盘（暖色像素只有暖白点 4–15 px），“两盏 Lichtchen”只有一盏（§6·4c LIP4 196.1 表盘提亮到 `#F2B169`）——如果表盘归车厢 / 本地，请在 README 写明，审片按“合成后”看。
