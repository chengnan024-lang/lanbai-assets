## 3. 银河点燃线 g(t)

- **按光源点燃，不碰曝光**（圣经 E18）：星点在 F13 一帧全部出现（+0.00 EV），亮度的上升全部来自辉光与星空底。
- **限速不限时长**：在五个视向（正前方、抬头 60°、天顶 85°、银心、向下 60°）上量 L(g)（真 shader + 贴星 + S9a 调色，天 2×2 超采样，显示线性亮度的平均，地板 0.004 按调色后的值 0.00184）。最极端的是**正前方**（银心在左前方的视野里）：L 从 0.0021 涨到 0.032 = 3.00 EV。按 0.85 EV/秒是 3.5 秒，**T 取圣经的 4.2 秒**（不比圣经快）。g(t) 让正前方的 L 按 EV 线性从 L(F13) 涨到 L(满)，表在 `Act09_StarSea.json` 的 `ignition.g`（每 0.05 秒一个）。v1 是 4.45 秒：那时的银河是生成的、更亮更软（正前方 3.77 EV）。
- 爬升律（同一条曲线，每个视向）：最坏 **0.18 / 0.72 / 1.43 EV**（0.25 s / 1 s / 2 s，正前方），全部通过（`Data/ignition.json`）。点燃满时只有天的 APL：正前方 36、抬头 27、银心 31（v1 是 46.7）。
- **在 Unity 里重新标定**（带车厢）：F13 那一帧的正前方截图平均亮度 C、g = 1 时 G（再加 g = 0.25 / 0.5 / 0.75 三张求 L(g)）；T = max(4.2, log2(G / C) / 0.85)；重算表。带车厢时跨度会小（车厢暗），T 多半回到 4.2 秒附近。

## 4. 驱动写什么（`LanbaiAct09Driver`）

| 全局量 | 值 |
|---|---|
| `_Udon_SkyBlend` | (0, 1, 夜层, 1)，1001.21 起 |
| `_Udon_SkyFx` | (0, 0.85, 0, 1)：蓝时的带留着，被夜层盖住 |
| `_Udon_GalaxyGain` | (g(t) × (1 + 0.8 x^2.5), 0, 0, 1) |
| `_Udon_StarGain` | (F13 起 1，否则 0, 4 + 4 x^2.5, 50 + 150 x^2.5, 1) |
| `_Udon_ZenithColor` | (夜色 + 增益 × 星空底增量, 1)，1009.21 起（**镜子读它当星空底**） |
| `_Udon_Fog` | (0, 0, 0, 1)：雾关 |

第一批星用自己的材质（`_UseGlobalGain` = 0）和 MaterialPropertyBlock（`_Gain`、`_OrderFade`），不碰全局量。主星和天问的星在 F13 之前 renderer 关着（省开销）。
**交接**：1001.21 之前 `_Udon_SkyBlend / _Udon_SkyFx` 归第 8b 幕（「云」）的驱动。

## 5. 星的亮度

- 主星：`_StarScale` 1.6、`_MagRef` 0、`_MagSlope` 0.5（物理是 1；压缩到 0.5，6.5 等的星也读得出）、FWHM 1.6 px、最亮 50 颗 ×4。0 等星的峰值线性 6.4（会 bloom），6.5 等 0.08。
- 天问的 16 颗星：字心（`Fonts/strings_all.json` 的 P09_Tianwen 排版：方位 0°、仰角 +8°、50 m、字高 2.2°；每个字心 = 基线上 0.38 em），HDR 峰值 4 × (0.4 + 0.6 × 笔画/12)（3 画 2.2、12 画 4.0），颜色 `#F2F6FF`。
- 第一批星：真星的星等 × 0.55，色 `#E8EEF8`。

## 7. 诚实的已知弱点

- 满亮时正前方左侧的银心（暖尘）是画面里最亮的一块，只有天时正前方 APL 36（圣经 30 是带车厢的整帧）；要压的话在 `Act09_StarSea.json` 里把 g 的上限乘 0.85，等带车厢的截图再定。
- 1008.6 那一帧（v1.1 起）：最后的光是贴着地平线的一线余晖。夜遮罩在地平线以下按 4 倍仰角算，地平线以下先黑；v1 是一块浮着的椭圆、更早是圆角矩形。
- 星的星等压缩（0.5）和亮度是按“看得见、F13 那一帧仍在地板以下”定的，满天星的密度感要等头显里看。
- 天问的 16 颗星是规整的两行点阵（就是字的位置）；字暗下去以后读作“一个小小的星座”，是圣经的意思，但在缩略图里像一行虚线。
- 参考帧没有镜子、没有车厢、没有字；APL 是“只有天”的数，不能直接和圣经 §2.2 的整帧 APL 比。
- 第一批星的出现时刻（994.06 → 997.06）是我定的（圣经只说“在天顶出现”）。
