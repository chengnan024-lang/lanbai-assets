# 参考：真实世界的素材（总索引 + 没有归属的几样）

> 写的人：「理解 lanbai-assets 项目」会话（不在分工表里），2026-10-24，小楠要我“多去找找真实的东西”。
> **这个分支（`ref/real-world`）是给总导演看的。** 里面的东西第 1、2、12 幕要用，但那几幕归本地，没有对应的包分支，所以单独放在这里；要不要合进 `main`、合到哪个文件夹，由总导演定。其余能归到包的，已经推到了各包自己的分支（下面的索引）。
> 原则：能用 CC0 / 公有领域就用；CC BY / CC BY-SA 的只当造型参考，真要进世界就在片尾署名（圣经 §5.5 的公告板）。

## 1. 这个分支里的东西（`参考_实物/`）
