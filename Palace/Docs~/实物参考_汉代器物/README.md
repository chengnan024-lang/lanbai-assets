## 怎么用（建议）

1. **只借结构和比例，不借颜色**：陶楼的绿是铅釉，不是建筑的颜色。宫殿的颜色照圣经（朱与靛、淤泥、灯旁的金朱）。也别让宫殿看起来像一件放大的陶器：陶楼是“缩小的真建筑”，要从它反推回真建筑的尺度和构造。
2. **对你考据里标【推测】的比例**：柱高和开间、腰檐出挑、平座的高度、插拱的出跳，可以在 49519、49520 上量一遍。
3. **两座“立在水里的楼”**（49521、1989.71）：不是要照抄它们的造型，而是说明“水中的汉代楼阁”在汉代人的想象里本来就有，宫殿的立意有实物撑腰。
4. **漆**：耳杯和漆盘残片给了漆面真实的光泽（不是塑料感）和云纹的笔意，正好对应圣经的楚漆细节。
5. 阙：你考据里已经有高颐阙、冯焕阙这些实物；这次我没找到开放授权的阙的照片。
