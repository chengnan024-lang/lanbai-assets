## 一句话

深水里一座汉代的宫殿安静地亮着：两列青铜灯在水下燃烧，一直排到大殿开着的门，暖光铺在台基上，银鱼绕着它缓缓转圈——没有人。**它就是那辆停在站台的车，淹没了**：黑暗中一个从外面看到的、亮着的竖向开口，光铺在前面一块湿的表面上。

## 怎么量

- 渲染：`Palace/Source/scene.py`（Cycles，烘焙灯按 Unity 的 InverseSquared + 范围窗，灯组分开）→ `post.py`（LanbaiFog 式雾、无雾的发光体、`_Udon_PalaceVeil`、S7b 调色 + bloom）→ 量数用渲染标准台的 `lbh/measure.py`（与美术审片同一套定义）。
- 爬升与闪烁：灯焰只换形状不换亮度；行列里每对灯的车下扫光由海的驱动管（车处 E 0.15）。§1.8 的录像 (d) 668–735 s、805–820 s 由本地录。
- 性能：≤ 40 个合并网格（D-27 #1），宫殿窗口 ≤ 6.4 ms（含阴影平行光）；透明只有灯焰 / 灯晕 / 门口光卡，FSE 用标准台 `--fse` 量。

## 形制（总导演已裁）

汉制、直坡屋面、檐口平直不起翘、柱头斗拱（一斗二升 / 三升 + 曲栱）、重檐四阿；正脊两端只起翘 + 很克制的鱼尾形；长信宫灯只留灯头立在素铜柱上；青铜 `#BA926A`，暗处按电介质。不许：紫禁城 / 明清、龙雕像、神灵、人、字、宫殿内部有东西、第二个物种、青橙配色、满画面的朱红。
