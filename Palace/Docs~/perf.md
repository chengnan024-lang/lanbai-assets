# 宫殿 · 性能账（给总工程师的账本；估算，没在 Unity 里量过）

依据：圣经 §1.9（宫殿窗口热点 6.4 ms，含阴影平行光 1.0 ms；644.96 → ≈875 s）、D-27 #1（≤ 40 个预合并网格）。

| 项 | 数 | 说明 |
|---|---|---|
| 网格（renderer） | **31**（≤ 40） | `Models/tri_counts.json`；LOD0 / LOD1 各算一个 |
| 三角形（全 LOD0） | **299,894** | 殿 62k、鱼鳞屋 22 座 77k（4 块）、灯 30 盏 40k（6 块）、银鱼 100k（一张网格，1 500 × 67）、阙 14k、台地 5k、海草 1k |
| 绘制调用 | 约 70（ForwardBase）+ 同量的阴影 / 深度 pass | 殿一个 renderer 有 8–10 个子网格（材质）；**没有 ForwardAdd**（宫殿不受实时点光，D-24） |
| 透明 FSE | ≤ **0.14**（F7）| `Docs~/fse.json`：灯晕卡 + 灯焰 + 门口光卡；车厢玻璃 0.7 另算 |
| 粒子 | 0 | 鱼是网格，不是粒子系统 |
| 贴图 | 22 张 PNG，2048²（灯焰 1024×1024、灯晕 256²） | Crunch DXT 90 / 法线 100（`LanbaiPalaceImport`）。显存估 ≈ 90–110 MB（7 套 × 3 张，含 mip）。**超了可以把 Mask 降到 1024**（−20 MB），细节看不出 |
| 光照贴图 | 估 2–3 张 2048²（BC6H） | 台地 0.25、殿 / 屋 0.6、阙 0.8、灯 2（× 4 texel/m） |
| Udon | 每帧 30 次 TransformPoint + 选 8 + 32 次 SetGlobalVector | < 0.05 ms |

**片元成本**：`Lanbai/Palace` 每像素 8 盏解析 GGX + 淤泥值噪声（3 层 × 8 次哈希）+ LanbaiFog + veil。最贵的是宝贝的 8 步视差（只在阙身、40 m 内）。大部分画面是水（海的穹顶）和车厢。
**砍的顺序**（auto-lite，圣经 §1.9）：鱼 1 500 → 700（驱动的 `lite`）→ 淤泥噪声降成 1 层 → 宝贝视差关（`_POMFade` 0）→ 灯晕半径 1.5 → 1.0。
