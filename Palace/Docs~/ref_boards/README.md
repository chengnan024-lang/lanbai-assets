## 「网络搜索协助」读原文核实的结论（2026-10-24，原文与 URL 见该会话的回信，摘要如下）

1. **鸱尾**：“柏梁殿灾…越巫言海中有魚虬尾似鴟…”出自《太平御覽》卷一八八转引的《唐會要》（今本《唐會要》卷四十四作“蘇氏駁曰”一段，说汉武帝起建章宫时“設鴟魚之像於屋脊”）；《漢書·郊祀志》原始记载只说“復起屋，必以大，用勝服之”，没有鸱。梁思成《中国建筑史》：汉代“脊端以瓦當相疊為飾，或翹起，或伸出，正式鴟尾則未見也”。文献最早的鸱尾：《晋中興書》，东晋太元十年（385）。→ 总导演 10-24 定：照考据做。**第 6 轮已改成正脊起翘 + 瓦当相叠**（`kit/hall.py` 的 `stacked_wadang`），阙只起翘。
2. **屋面**：汉代屋面与檐口基本是直线、无举折；“反宇”是大屋檐口的边头瓦微微反上（薛綜注《西京賦》），不是曲面。坡度：《考工記》“瓦屋四分”（鄭玄注“以其一為峻”）→ 约 **26.6°**。我们 28–30°（大殿）、28° / 36°（阙），接近；阙的上檐偏陡。
3. **高颐阙**（徐文彬等《四川汉代石阙》1992）：右阙主阙通高 5.9 m，阙身 4 层整石、高 2.64、长 1.62、宽 0.90 m，**重檐庑殿**；子阙单檐 2.94 / 3.39 m；两阙相距 13.6 / 13.2 m。→ 我们的阙按 6.8 倍放大，阙身截面应约 11 × 6 m；受海的布局限制（右阙离车 9 m、缝 6 m）我们是 6 × 10（x × z），从车上侧看读得出，正看偏瘦。
4. **长信宫灯**：通高 48 cm、15.85 kg、六部分分铸；灯盘直壁平底、**内外两重壁成凹槽**，屏板嵌在槽里，一片可左右推开；**灯盘有把手可转动**，**中心有铜扦子插火烛**；烟经右臂入中空的身体。灯盘直径、屏板尺寸要查《满城汉墓发掘报告》（1980），网上没有。→ 灯头补了把手和铜扦子（`kit/lamp.py`）。
5. **斗拱**：一斗二升（彭山崖墓、高颐阙楼部第二层“均為一斗二升”）、一斗三升（明器“頗常見”）、重栱都有；栱形有曲线、斜杀折线、S 形（只见于石阙）；汉代**没有**“以栱定比例”。→ 我们用一斗二升 / 一斗三升 + 曲栱，阙用一斗二升，相符。
6. **紫贝**：王逸注《河伯》只说“紫貝作闕”；洪興祖補注引郭璞“以紫為質，黑為文點”、陸機“白質如玉，紫點為文”。→ 我们的紫底浅斑（圣经 `#5B2A4E` / `#B89AB0`）在两说之间。
