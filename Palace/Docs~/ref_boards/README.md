## 可能时代错位的地方（明知故犯的标“梦”，其余是待核）

| 东西 | 问题 | 处理 |
|---|---|---|
| **鸱尾** | 能确认的最早出处是北魏（《水经注》）；“柏梁殿灾…越巫…尾似鸱”的故事出处待核 ⚑。汉代正脊两端只起翘 | 只起翘 + 很克制的鱼尾形（D-29），不做吻兽 |
| **鱼鳞瓦**（圆头鳞片屋面） | 汉代没有鳞形瓦的实物；是《九歌》“鱼鳞屋”的字面 | **梦**：只用在“鱼鳞屋”上，大殿和阙用汉式筒瓦 |
| **紫贝阙**（阙身贴宝贝） | 神话；“紫贝”指哪种贝待核 ⚑ | **梦** |
| **门不在大殿正中**（第 8 间开门） | 汉代宫殿按中轴对称、正中开门 | 构图的代价（海的约定：门在神道轴线上、车左 18 m、右边是暗的空旷），写进了 `给总控.md` |
| **九开间** | 汉代有偶数开间、中柱居中的例子（孝堂山石祠），也有奇数开间 | 取奇数（门要在一间的正中） |
| **钩阑**的斜格 / 卧棂 | 形制取自画像石，细部是推测 | 待核 |
| **长信宫灯式的灯排成两列** | 长信宫灯是室内的小灯（48 cm），放大成 1.9 m 的“行道灯”是我们的设计 | **梦**（圣经 §6·7b 要的） |
| **重檐四阿** | 汉代有没有重檐庑殿的大殿，证据是陶楼的腰檐与画像石 ⚑ | 按陶楼的层层腰檐理解 |
