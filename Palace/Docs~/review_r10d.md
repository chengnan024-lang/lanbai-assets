## 遮挡淡出本身

**shader 和 Python 是不是同一个式子：是。** 逐行对过：提前返回、坡宽坡深按崖口处 z 的 smoothstep 权重（`_CliffSlopeZ` (48, 54, 296, 306) 和 Python 的 z0 / zf0 / zf1 / z1 同一组数，排列顺序不同）、剖面（圆顶 k²/0.3，之后 k − 0.075，再除以 0.925；小坡 k^1.5）、起伏上包络 0.52 · w · sin πk、石壁四个点 edge + 0.9j / −D − 4.4j、余量 0.08、下唇 x −8.6 y −14.2、淡出宽度 `fade_s · sink · (1 − tL)`。生成的 CliffEdge / CliffSlope 和 `CLIFF` 一致。

**是不是只往“藏”的方向：是。** 748.3–877 s 之间，`cliff_vis > 0` 而视线从外面穿进岩体的情况是 0 次。上限都核过（坡面起伏实际最大 0.520 m；石壁外凸夹在 −7.1；下唇最低 −14.11，模型取 −14.2）。唯一的命中在 804.25–804.30：远列 12 盏的视线擦过神道铺石外沿（x −11.6、高 0.12 m），那时可见度只有 0.005–0.011，不阻断。保守的代价是藏得早：近列真几何要到 823–826 才被挡，模型 820.85 / 821.95 就淡完了；远列真几何 816.3–816.6 就能看见，模型 818.1 才淡进来。可以接受。836–845 那一段藏得太久，见新阻断 2。

**淡出是不是 ≥ 1 s：是。** `eye(t)` 在 745–880 之间下沉最快正好 1.5 m/s，F7 以后 x、z 不动。逐盏扫下来最短的是 1.00 s；近列淡出 3.8–4.0 s，远列在 803 前后淡出 1.23 s。
