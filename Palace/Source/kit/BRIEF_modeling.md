# 建模约定（给建模 agent）

- 只写 `Palace/Source/kit/<你的模块>.py`，以及预览脚本 `Palace/Source/kit/preview_<模块>.py`。不要改别的文件；不要 git 提交。
- 几何一律用 `kit/common.py` 的 `UB`（Unity 轴：x 右、y 上、z 前，米）和 `lathe` / `hip_roof`，面按“从外面看逆时针”给（`UB.box` 已经对）。写完用一个小测试确认法线朝外（参考：对每个闭合部件，面法线 · (面中心 − 部件中心) > 0）。
- 模块函数返回 `UB`，不碰 bpy：`build(lod=0, **params) -> UB`。LOD0 = 近看（≤ 40 m），LOD1 = 远看（> 80 m，只留轮廓：屋顶、柱、台基，省掉斗拱细节、瓦垄、钩阑）。
- 材质槽只用 `common.SLOTS` 里的名字。含义：Lacquer 朱漆（柱、梁、门、栏）；LacquerBlack 黑漆（门框、磨损底、窗格）；LacquerBand 梁枋上“黑底朱绘云气纹”的带子（UV 横向沿梁，1 UV = 4 m）；Gilt 鎏金铜配件（门环、柱头箍）；Bronze 铜；Stone 台基 / 阶 / 阙基的石；StoneDark 墙；FishScale 鱼鳞屋顶（珍珠母）；Cowrie 紫贝阙阙身的宝贝贴面；Tile 屋面（筒瓦、板瓦、脊、瓦当）；Wood 暗木（直棂窗、门板内侧）。
- UV0：世界尺度（`UB.add` 不给 UV 就自动三向投影，米 / TILE）。梁上的 LacquerBand 要给沿梁的 UV（u = 沿梁米 / 4，v = 横截面 0..1）。
- 形制：先读 `Palace/Docs~/research_han.md`（考据）和总导演的裁决：**汉制，直坡屋面，檐口平直、转角不起翘；正脊两端只起翘 + 很克制的鱼尾形（不做明清吻兽）；不许出现**：翼角起翘、曲面屋顶、仙人走兽、成攒的密斗拱、须弥座、明清彩画、任何文字、龙雕像、人。参考照片（汉代陶楼、漆器）：`Palace/Docs~/实物参考_汉代器物/`（用 Read 工具看 jpg）。
- 它们在深水里，几乎全靠宫灯和门光照亮、雾在 38 m 吃掉一半：**剪影和大块面最重要**，细节放在会被灯照到的低处（台基、柱脚、门、阙基）。从下面（F7p，车在台地下缘以下往上看）会被看见：**每个物体都要封闭**（有底面），不许看见网格内部或切开的面。
- 三角形预算（LOD0 / LOD1）写在任务里；超了说明为什么。
- 预览：`~/bpy/bin/python kit/preview_<模块>.py` 渲 3 张小图（480×270，Cycles 16 spp，灰模 + 槽位的大致颜色，正面 / 3/4 / 从低处仰看）到 `/tmp/pal/kit_<模块>/`，自己看、自己改，至少改两轮。预览可以参考 `whitebox.py` 的灯光写法，或者简单用一盏太阳 + 环境光。
- 交回：模块文件路径、三角形数、你自己看了预览以后还不满意的地方。
