## 2. 车厢（Fortepan 档案，1960 年代苏联公交车里）

`车厢_01…03_Fortepan.jpg`：黑白照，乘客坐在车里。看的是：窗的上半截能推开的小气窗、座椅靠背顶上的扶手杆、窗框的粗细、车厢有多亮。都是 CC BY-SA 3.0（Fortepan）。Commons 上还是找不到 PAZ-672 本身的车内照片。

## 3. 收音机（D-14：仪表台上、方向盘右边）

圣经 §4.4：七八十年代的皮套晶体管收音机，刻度窗奶白、**只有刻线没有数字**、红针。车是苏联的，收音机也用苏联的，正好配成一套。

| 文件 | 看什么 | 授权 |
|---|---|---|
| `收音机_Selga_1963.jpg` | 棕色皮套、顶上一条横的刻度窗、背带。**最像圣经写的那台** | CC BY-SA 3.0 |
| `收音机_Geolog.jpg` | 棕色皮套 + 拉丝金属格栅 + 一排旋钮（圣经：格栅拉丝穿孔铝、旋钮滚花铬） | **CC0** |
| `收音机_Sokol.jpg`、`收音机_Sokol-403.jpg` | 黑皮套的 Sokol，刻度窗的排版 | CC BY-SA 3.0 / CC BY-SA 2.0 |

做的时候：刻度去掉数字（圣经），厂牌字样也去掉。你的 `Textures/Cabin_RadioDial_512x256.png` 可以对照 Selga 那条刻度窗的比例。
