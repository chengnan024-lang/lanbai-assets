# D-13 · 里尔克诗块的候选位置（PAZ-672 车，主座位，t = 140）

## 约束和量法
- **诗块**：德文两行 EB Garamond Italic，按 2.0° em（圣经 §7.3 允许 2.0–2.2°；2.2° 时第二行 23.2°，块太宽，三个候选都放不下），第二行 21.1°；中文译文两行 1.8°。整块（含行距）约 **21.1° × 10.3°**。日文 / 英文译文都比中文宽（日文约 20°），也在 21.1° 以内。
- **挡风玻璃**（这辆车）：右片 −26.5 … +20.5°，中柱 −28.45 … −26.70°，左片 … −28.5°。按 D-04 / D-13 离中柱和 A 柱都 ≥ 4°，所以诗块能放的方位是 −22.5 … +16.5°（要整块在右片里）。
- **裂口核心**（137.30 → 147.30）：按 `Gate/GateLayout_v2.json` 的 gate_z、h_bus、tear_H 和圣经 §6·4 的透镜形状算，核心在方位 0°（±1.5 … 2°）、仰角 −1°（云顶处的脚）… +12°（137.3）→ +16°（147.3）。块宽 21°，所以**块不可能放在伤口旁边**（右边最多到 +16.5°，块中心最多 +5.9°，左边沿就会压到 0°）。三个候选都放在云顶线以下，顶行离伤口的脚 ≥ 1.5°。
- **月**：−12° / +8°，直径 1.2°。
- **竖直**：圣经 §7.3 中心在 −15 … +10°（优先 −9 … +8°）。

## 渲出来才看到的
- **B：译文压在收音机后面**（D-14 的收音机在 −20°/−12°，块的下半在 −22 … −1° / −13 … −3°）。表里没算收音机。

## 我的建议：A
- 读的顺序最顺：眼睛先到伤口，往右下一落就是诗，诗的右边是开着的车门（+21° 起）。
- 巨像 1 在诗后面升起时站在伤口右边，和圣经原来的“巨像 1 在 +24°、诗在 +20°”是同一个关系（都在伤口右边），只是近了。
- 离 A 柱 4.5°，刚好过 D-04 的 4°。
B 的译文被收音机挡住，巨像 1 还会顶到月；C 的译文压在雨刮上，巨像挤在伤口脚边。
