## 0. 先说结论

| 部件 | 照片里的样子 | 依据 |
|---|---|---|
| 立柱 | 地板到顶棚的竖管。管径目测和我们的 Ø32 差不多（估的，没有尺寸） | `F02`、`F04`、`F05` |
| 落地座 | 一个往上收细的铸造套筒，坐在一块**三瓣的底板**上，三颗螺栓固定在地板上；套筒侧面一颗紧定螺钉 | `F04`（放大看过）、`F05` |
| 顶上 | 一块圆法兰贴着顶棚，下面接一段短套筒 | `F06`、`F07`、`F11` |
| T 形抱箍 | 铸造的对开套抱在立柱上，侧面伸出一个短管座接横杆，一颗螺钉锁住 | `F05`（放大看过）、`F04`、`F02` |
| 横杆到侧墙 | 从立柱的 T 形抱箍横到侧墙，墙上一个铸造托座、两颗螺钉 | `F04` |
| 门口扶手 | 门口立柱上一个 T 形抱箍，接一根弯管：先横过去，再弯下来，落到踏步边地板上的座里 | `F05` |
| 顶上的纵向扶杆 | 顶棚两侧各一根，用铸造的吊座挂着（上面贴顶棚，下面一个抱环）。672M 的是**亮的金属管**（Kolesa `salon-6`，据 README §6.2）；trolleway 的是奶油色漆的 | `F02`、`F03`、`F06`；Kolesa |
| 立柱上的小盒 | 立柱上用两个抱箍夹着一个灰色（或黑色）小盒，在头的高度。是检票打孔器还是停车按钮，看不清，**不能确定** | `F02`、`F06`、`F11` |
| 停车按钮 | 672M 有“叫司机停车的按钮”（Kolesa 文字）。在哪、什么样，**没有照片** | Kolesa 文字 |
| 立柱的位置 | 门口、轮罩单座旁边、车尾长椅前面、司机隔板后面；不是每一排都有 | `F02`、`F03`、`F05` |

我们的 r1（`poles.py`，1e9cafa）和照片比：

- 落地法兰：r1 是圆盘 + 短套 + 三颗螺钉；照片是**三瓣底板 + 更高的收细套筒 + 侧面一颗紧定螺钉**。可以照照片改。
- 顶扶杆的吊挂：r1 是吊杆 + 对开管夹；`F06` 是一体的铸造吊座 + 抱环，样子接近。
- 停车按钮：r1 在右边第一根（`PoleR0`）和左边第二根（`PoleL1`）立柱上各放一个，Unity y 1.50（离地板 0.88 m），是我们自己定的，照片里没有依据（见第 4 节）。

## 2. 和圣经、裁决的冲突（汇总）

1. **材质**：圣经 §4.2 立柱与顶杆是 Ø32 不锈钢 `#C0C3C4`，光滑度 0.55，握手高度 1.0–1.8 m 处 0.80，金属 1。672M 的顶扶杆是亮金属（Kolesa，一致）；672M 的立柱是漆的还是亮的，照片没说清；trolleway 全是奶油色漆，**不照**。照圣经。
2. **停车按钮**：D-36 #2 要有。位置和样子我们自己定的，没有照片依据。按钮上不许有字（D-28 #4）。
3. **踏步**：花纹铝板、没有黄条（`F05`）；圣经要铝包边 + 黄色安全条。照圣经。
4. **灯色**：照片里都是暖光，不照（圣经 §4.3）。
5. **高光闪烁**：细的亮管子在 VR 里最容易闪，D-40 #4 的几何高光抗锯齿主要就是为它们。

## 3. 旧（D-40 #3）在立柱和扶杆上落在哪

- **手**：握手高度被摸亮（圣经 0.80）；门口立柱和门口扶手最亮；T 形抱箍的边被摸亮；顶扶杆上，乘客站着抓的那几段亮一点。
- **脚**：落地座被鞋踢花，底板四周积灰，地板胶在底板边上有点翘。
- **水**：落地座和地板之间的缝会积水，缝里可以有一点锈色或黑垢；**立柱和扶杆本身不许有锈**（手碰得到）。
- **维修**：一两颗换过的螺栓（颜色不一样），一个后换的抱箍。

## 4. 还缺什么，哪张照片能定

| 缺的 | 为什么要 | 哪张照片能定 |
|---|---|---|
| 672M 的立柱是漆的还是亮金属 | 材质和闪烁都看它 | Kolesa `salon-2` / `salon-3` / `salon-6` 放大；自由授权的 672M 车内 |
| 停车按钮的样子和位置 | D-36 #2 要做，现在是我们自己定的 | 672M 车内立柱或侧墙的特写 |
| 立柱上那个小盒是什么（打孔器、按钮还是别的） | 如果是停车按钮，就有了样子 | Flickr 上 trolleway 的原图（比仓库里的 1600 px 大）或别的照片 |
| 672M 的吊座、管夹 | 顶扶杆在 0.6 m 看得见 | Kolesa `salon-6` 放大 |
| 672M 立柱的位置和数量 | 现在是照 672（多半）的 trolleway 那辆推的 | 车内平面图（1980 年使用手册，只给链接 <https://dokumen.pub/672-8nbsped.html>，版权不明） |
| 管径、法兰尺寸 | Ø32 是圣经定的，照片只能目测 | 带卷尺的照片 |
