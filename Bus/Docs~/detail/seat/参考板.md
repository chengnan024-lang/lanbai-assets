## 0. 先说结论：672M 的乘客座椅怎么做

依据：总导演 10-25 给的事实（`实物参考_PAZ细节/README.md` §6.1，Kolesa 试驾的那辆 1989 年 672M），加上 trolleway 那辆（多半是 672）`F01`–`F04` 看得见的框。README 说两辆车的座椅结构一样，只有颜色和管套不一样；照片上看也是这样。

### 0.1 双人座（单人座同一个做法，窄一点）

| 部件 | 怎么做 | 依据 |
|---|---|---|
| 侧框 | 一根**漆过的**弯管，不是镀铬。每一侧这样走：从地板上的**前脚**往上，到座垫前沿 → 沿座垫侧面的底下往后 → 在座垫后角折上去，顺着靠背的后仰沿靠背侧边上去 → 到顶弯过去，**横贯整个靠背** → 从另一侧下来。座垫后角底下再弯出一个**下圈**，落到**第二个脚**上 | `F04`（看得最清楚）、`F01`、`F02` |
| 脚 | 小钢板，**用螺栓固定在地板上**；`F04` 里两块脚板上各看得见一颗螺栓 | `F04`、`F01`、`F02` |
| 框上的小件 | 靠背侧管和座垫侧管相交的地方有一块折出来的连接板（同色漆）；靠背侧管上有几颗小螺钉，把靠背固定在管上 | `F01`、`F04` |
| 顶管的管套 | **横的一段整条套着黑色人造革管套**，Ø 约 55 mm，一道接缝；**两头的弯角不包，露出漆过的管子** | Kolesa（据 README §6.1）；总导演 10-25 |
| 管子、背板的颜色 | 漆的。按圣经座椅框那一行 `#3C3E3D`（总导演另有裁决就照裁决）。原车（Kolesa）是浅青绿，trolleway 是奶油色，**都不照** | 总导演 10-25 |
| 座垫、靠背 | **各是一整块**枣红人造革（圣经 `#5A2126`），**不分格，没有竖条、横条绗缝**；边上一圈浅色（米白）嵌线。座垫厚，前沿圆。靠背的人造革从上沿包过去，管套压在它上面 | Kolesa（据 README §6.1）；`F03` 看得见“整块”（trolleway 的嵌线和面同色，看不出来） |
| 背板（靠背的背面） | 一整块冲压薄钢板，**四边压出一圈凸边，中间凹下去**，和管子同色，边上几颗小螺钉 | Kolesa（据 README §6.1）；`F01` 的白背板是同一类板 |
| 靠背高度 | 靠背顶（连管套）≈ 侧窗下沿，宁低勿高。**我们的窗台比原车低，见 0.3** | Kolesa（据 README §6.1）；`F02`、`F04` |

### 0.2 两种不一样的座

- **轮罩上的单座**（`F04`）：一块方方的靠背垫，**没有顶管，也没有管套**；座垫坐在一根管子撑起的座架上，座架立在轮罩顶上。旁边的立柱伸出一根横杆到侧墙，挡在座位前侧。
- **车尾五人长椅**（`F03`）：一整条靠背垫，**没有顶管**；座垫看上去是三块拼的：左右两块长的、中间一块短的（2 + 1 + 2，正好五个人），立在奶油色的管脚上。README §6.1 写“一整条座垫”，照片上是三块；请用 Kolesa `salon-3` 再核对一次。

### 0.3 靠背高度：要总导演定

- 原车：靠背顶 ≈ 窗台线。窗台离地板约 0.85–0.9 m（照片目测的估计，没有找到写尺寸的资料）。
- 我们：窗台 `WIN_SILL` 1.30 − 地板 `FLOOR_Y` 0.62 = **离地板 0.68 m**（`bus_spec.py`），比原车低 0.17–0.22 m。座垫面离地板 `SEAT_H` 0.40 m。
- 所以在我们的车上，“靠背顶 ≈ 窗台”会做出一个**比原车矮一截**的靠背：靠背顶只比座垫面高约 0.28 m。反过来，按原车的绝对高度做，靠背顶会比我们的窗台高 0.17–0.22 m，后排的人往外看时，侧窗下沿会被前排靠背挡住一条。
- 现在 `compare.png` 上的 r4：顶管在座垫面以上约 0.635 m，也就是离地板约 1.03 m，比上面两种都高。
- 不管选哪种，都要重跑 `viewcheck.py` 和座位遮挡（`seats_occlusion_1deg.json`、D-37 每个座位的诗句位置表）。窗台本身是视窗合同的一部分，我不建议为了靠背去动它。**这件事我不替总导演选。**

### 0.4 r4（现在 `compare.png` 上那版）和 672M 不一样的地方

座椅正在照 672M 重做，这张表只是一份对照清单。

| r4 | 672M |
|---|---|
| 顶管是铬（照圣经 §4.2 原文） | 漆管，和框同色 |
| 管套只包过道那一个弯角 | 包横的一段，两个弯角都露管 |
| 靠背正面三道横向绗缝 | 整块，只有一圈嵌线 |
| 背板：一块平板，上下两排圆头螺钉 | 冲压板，四边凸边、中间凹，边上几颗小螺钉 |
| 过道侧一根斜腿 + 圆脚座（三颗螺栓），墙侧一块托架 | 侧框 + 下圈 + 两块脚板 |
| 座垫底下一块托盘 + 一圈管框 | 照片里看不到座垫底下（缺，见第 4 节） |
| 靠背顶离地板约 1.03 m | 见 0.3 |

### S3 · `F01` 双人座的背面

- **文件**：[`F01_座椅背面_靠背顶整条软套_白背板_铆钉_31583330165.jpg`](../../实物参考_PAZ细节/flickr/F01_座椅背面_靠背顶整条软套_白背板_铆钉_31583330165.jpg)
- **型号**：672（多半）。同一辆车 `F05` 门边的铭牌露出“…З-672”，后面没有 М；铭牌被手挡住一半，所以只说多半。座椅后来重包过红色人造革。
- **照的是什么**（我看到的）：过道那一端，从斜上方看一个双人座的背面。奶油色漆管从靠背侧边上来，到顶弯过去横贯整个靠背；横的一段整条套着红色软套，套子端头齐口，**两个弯角都露管**；过道那个弯角的漆掉了一片，露出深色的底。靠背侧管上有三颗小螺钉；侧管和座垫侧管的交点有一块折出来的连接板。白色背板：上沿一排五六颗小圆头钉，两侧边上也有几颗，中间一个旧孔，下沿是一道浅弧，下面露出红色人造革。窗边沿墙的地板上有一条奶油色的暖风箱，带斜的通风缝。
- **借**：顶管怎么横贯、管套只套横段、弯角露管；连接板、侧管上的螺钉；背板的形（四周一圈边，钉子沿边走）。**过道那个弯角的掉漆就是 D-40 #3 说的“手”**。
- **不照搬**：红色软套（672M 是黑的）、奶油色管、白背板、红色座面（总导演 10-25：不照它的颜色）。
- **冲突**：圣经 §4.2 的铬扶手（同 S1，已定漆管）。
- **来源与授权**：Artem Svetlov（trolleway），CC BY 2.0，[Flickr 31583330165](https://www.flickr.com/photos/trolleway/31583330165/)。可以进世界，署名照 [`../署名与授权.md`](../署名与授权.md) 第 4 节。

## 2. 和圣经、裁决的冲突（汇总）

1. **顶管**：圣经 §4.2 是铬 `#CFD1D3`。总导演 10-25：漆的，颜色按座椅框 `#3C3E3D`（另有裁决照裁决）。圣经铬扶手那一行，座椅不再用。
2. **管套**：圣经 §4.2 没有这一行，要一组值（黑人造革的反照率、光滑度、法线强度）。圣经对黑的东西有下限（“黑漆例外 ≥ 38”“黑亚麻例外 ≥ 38”），管套也该守。**请总导演给数。**
3. **嵌线**：圣经 §4.2 没有这一行。照片上是米白。请总导演给一个色（可以从圣经已有的奶白里挑，这只是建议）。
4. **背板**：圣经没有单独一行；照 10-25 的事实和管子同色，用座椅框那一行。
5. **靠背高度**：见 0.3，要总导演定。
6. **D-28 #4**：座椅上没有字，不冲突。`D08` 的铭牌不进世界。
7. **D-36 #2**（缝线、滚边、鼓起的座垫、弯管的座椅框和脚、扶手）：672M 是整块，不要绗缝条纹；“缝线”只剩嵌线那一圈和管套的一道接缝。D-36 没要求绗缝，不冲突。
8. **布局**：trolleway 那辆是 2 + 2；我们是右边单座、左边双座（D-28 视窗合同），不改。主座位压在前轮罩上（合同），而原车轮罩上的座是 `F04` 那种没有顶管的单座。**主座位用普通座（有顶管）还是轮罩单座（没有顶管），请总导演定**；r4 用的是普通座加两块托架。

## 3. 旧（D-40 #3）在座椅上落在哪

只写有原因的；不许整体叠脏图，宁少勿多。

- **手**：管套的上面（被抓、被压出亮和皱，接缝先开）；**两个露管的弯角掉漆**（`F01` 过道那个弯角就是这样）；座垫前沿。
- **坐**：座垫中间和前沿被坐亮（圣经 `#6A3434`，0.62–0.70）；接缝开裂，每座 2–5 处（圣经）。
- **脚**：脚板、下圈、侧框的下段被鞋碰得掉漆或发亮。
- **太阳**：靠窗那一侧的靠背上沿晒褪（圣经 `#7A4A48`）。
- **水**：座椅本身不碰水。脚板和地板之间的缝会积水，缝里可以有一点锈色；**管子上手碰得到的地方不许有锈**。
- **维修**：个别座换过的螺钉（颜色不一样），一条新一点的管套。
