## 0. 先说结论

### 0.1 最要紧的一条：侧窗是“左右两扇、全高推拉”，还是“下面固定、上面推拉气窗”？

**仓库里能看的照片，全是左右两扇、全高的推拉窗**：一扇在另一扇后面左右滑，中间一根从窗下框到窗上框的竖的会合框，窗扣在会合框旁边。

- `D02`（Commons 标题是 **672M**，UMMC 博物馆）：照的是车的**左侧（司机一侧）**，从外面看，每扇侧窗都有一根全高的竖框，竖框边上一个小窗扣；
- 右侧（门那一侧）：`ref/PAZ_04`（W13）、`D05`（PAZ-3201，车身和 672 一样）也是全高的竖框、没有横档（`D05` 分辨率低）。所以两侧一样，下面的结论对两侧都成立；
- `ref/PAZ_03`（明斯克）：同上；
- `F02`、`F03`、`F04`（trolleway，多半是 672）：从里面看也一样。框边一个黑色小圆钮；`F03` 右边那扇的会合框下端还有一个扣座。

没有一张看得见横档，也没有一张看得见上半截的小推拉窗。

可是有三处写的是另一种：

- README §6.2 的对照表写 Kolesa 那辆 672M “下面一大块固定玻璃，上面是推拉气窗”，**没写是从哪张照片看出来的**（`salon-7` 是下一行窗扣的出处，不是这一行的）。同一行 trolleway 那一栏写“一样（`F02`、`F04`）”，可 `F02`、`F04` 我放大看过，都是全高的窗扇、没有横档，和这句话对不上。这一行自己就前后矛盾，所以 README 说的 672M 分格也**没有证实**；
- 总导演 D-28b #6：“侧窗圆角，上半截是推拉的小窗（原车的分格）”；
- `window.py` r1（1e9cafa）照 Fortepan 做了横档 + 两扇推拉上扇，并且**去掉了全高的竖中梃**。可 Fortepan 不是 672（W11）。

**两种说法冲突，要总导演定。** 定之前先看 Kolesa `salon-7`、`salon-3` 里有没有横档。如果照照片做全高的竖框（左侧 `D02`，右侧 `ref/PAZ_04`）：主座位旁边的 WinR1 是 z 1.30–2.57，竖框在中间（z 约 1.94）的话，从眼位看大约在方位 +105°，正落在侧窗的诗的范围里（圣经 §4.1：右侧窗 +60°…+150°），要用 `viewcheck.py` 重量。

### 0.2 其余部件

| 部件 | 照片里的样子 | 依据 |
|---|---|---|
| 窗框（里面） | 一圈较宽的亮铝框，四角大圆角；玻璃四周一道黑胶条 | `F03`、`F04`、`F09` |
| 窗扣 | 672M：米白色圆塑料旋钮（вертушка），装在一块金属片上，卡在推拉窗边上，转一下就锁住；Kolesa 说形状像马自达的转子（据 README §6.2、§6.3）。trolleway：黑色小圆钮 | Kolesa `salon-7`；`F03`、`F04` |
| 窗上沿 | 一条横的铝压条，一排小螺钉；再往上是车顶两侧的斜面窗（弧面玻璃、黑胶条、奶白的拱形窗柱，柱脚一个小衣钩） | `F09`、`F04` |
| 两扇窗之间 | 内墙板，中间一条竖的铝盖条 | `F04` |
| 窗下沿 | 照片里就是铝框本身的下边，没看到单独的窗台板；双人座的管套大约在这条线上 | `F03`、`F04` |
| 内墙 | trolleway 是木纹板（修复时换的）；672M 是带装饰花纹的硬质纤维板（ДВПО，672M 和 672 的区别之一，模型局）；`D08`（672M）门边是金黄赭色光面漆的钢板 | `F04`、`D08`；README 第 3 节 |
| 外面的框断面 | 窗洞的翻边和胶条槽，玻璃没了才看得到；角是大圆角 | `D06` |

### 0.3 窗台高度

我们的窗台离地板 0.68 m（`WIN_SILL` 1.30 − `FLOOR_Y` 0.62），原车约 0.85–0.9 m（照片目测的估计）。窗台是视窗合同的一部分，不在这里改。它影响座椅靠背的高度，见 [`../seat/参考板.md`](../seat/参考板.md) 0.3。

## 2. 和圣经、裁决的冲突（汇总）

1. **分格**：照片（W1–W7、W13，车的左右两侧都有）是左右两扇全高推拉；D-28b #6 和 r1 是上半截推拉 + 横档。**要总导演定**（0.1）。
2. **窗框、胶条**：圣经 §4.2 窗框阳极铝 `#B8BBBD` / 0.45 / 金属 1，胶条 `#2B2B2B` / 0.30、细裂 0.5。照片是亮铝框、黑胶条，**一致**。
3. **内墙**：圣经下墙板奶白搪瓷 `#D9D4C5`；672M 是带花纹的硬质纤维板（ДВПО），`D08` 门边是赭色漆，trolleway 是木纹板。照圣经。ДВПО 花纹板是 672M 和 672 的区别之一，要不要加，请总导演定。
4. **窗扣颜色**：672M 米白，trolleway 黑，圣经没写。建议照 672M 的米白（只是建议）。
5. **窗台**：我们 0.68 m，原车约 0.85–0.9 m（0.3），视窗合同，不改。
6. **D-28 #4**：窗上不贴任何字。原车侧窗可以当紧急出口，常贴字；照片里没看到，也不加。
7. **窗帘**：圣经 §4.5 有窗帘，D-36 #2 要窗帘杆和挂环。`ref/PAZ_04`（W13）从外面看车里挂着窗帘，杆子看不到；这一组照片里没有窗帘杆。

## 3. 旧（D-40 #3）在侧窗上落在哪

- **水**：窗下沿的胶条和框角积灰、有水渍，胶条发白、开细裂（圣经 0.5）。照片里车外的锈在保险杠、裙边下沿、门下沿、轮拱（`D06`、`ref/PAZ_07`、`ref/PAZ_04`，W8、W14、W13），窗下沿都看不出锈。照 D-40 #3，窗上的锈最多只在车外窗下沿积水的胶条槽里，要轻；**车里的铝框不锈**。
- **太阳**：上沿的胶条晒裂、发白。
- **手**：窗扣、推拉窗扇边上手推的地方被摸亮。
- **维修**：一两扇的胶条比别的新、黑；换过的窗扣颜色不一样（建议，不是事实）。
- `D06` 是废车（后窗和一扇角窗的玻璃没了、大片锈），在旧的上限以外，不照。
