## 0. 一句话

**外形和性格照 PAZ-672，布局沿用你已经解好的合同。** 眼位 (0.55, 1.70, 2.05)、地板 0.62、天窗中心 (0.55, 2.62, 2.80)、主座位压在前轮罩上、门洞在主座位前面（D-12 的晨日 +30° 框在门里）都不变。为了这套合同，有两处要偏离原车（第 3 节），其余都照原车做。

## 1. 为什么是它

- **它本来就是“蓝白”。** 卡卢加那辆原车就是白上蓝下（`ref/PAZ_02`）。
- **它天生有天窗。** 车顶两侧的弧面上有一排斜面窗（俄文 окна в скатах крыши；标准型就有，只有山地型 672Г、北方型 672С、热带出口型 672Ю 取消了），夜里车内的管灯会从车顶边透出一圈光（`ref/PAZ_03`、`ref/PAZ_04`）。圣经“画框随宏大变宽：车窗 → 天窗 → 顶棚破洞”这条母题，在这辆车上是真实的结构。
- **它有一张脸。** 圆灯，两块像眼睛的格栅，面包一样的圆车顶。第 1 幕的站台、第 12 幕的醒来，都要观众对这辆车有感情。
- **它属于乡间公路和小站。** 原车的设计用途就是区县和城郊、客流小的线路（俄文维基）。`ref/PAZ_01` 那张雨雪夜开着灯的车，就是我们开场的气氛。

小楠也看过二代考斯特的照片，选了 PAZ；苏联味不算问题。

## 3. 和你的合同合在一起：偏离原车的两处

### 3.1 门挪到前轴前面（偏离原车）
原车的前门在前轮后面。照原车做，主座位就得坐在门后，眼睛离前挡约 3 m，前挡只剩一条窄带，又回到本地 v1 车丢 6 个目标的老问题。你的合同把门放在前轴前面、主座位压在轮罩上，这一点**保留**。PAZ 自己的后继车型 PAZ-3205（1989 起）前门就在前轮前面（这条凭记忆，请再核对），所以对这一家族来说不算离谱。门只做一扇（像 672M 的单门版），不要后门。

### 3.2 车宽（请你判断）
原车宽 2.44 m，合同的车壳是 2.08 m。PAZ 的样子很大程度来自它又宽又高的“面包”比例，按 2.08 m 做会像被压窄了。两条路：
- **A. 按原车宽 2.44 m**：主座位要仍然是靠窗座，而眼位是死的（门和别的包都在用），可以把**车身整体往左挪约 0.18 m**，让右侧壁仍在眼睛右边约 0.49 m。要核对：还有谁用了车的中线（`BusLayout.json`、门内的光斑投影、Director 的车厢包围盒、各包的车壳）。
- **B. 保持 2.08 m**，只借 PAZ 的外形语言。

我倾向 A，但这是技术上的取舍，你量了再定。车高（原车 2.95 m，合同 2.74 m）同理：车顶更高、天窗井更深，`SKY_C` 的玻璃高度 2.62 不变的话，井口可以做成你计划里的外八字。

### 3.3 挡风玻璃：照原车做两片，中间一根细立柱（我建议，请量）
PAZ 的脸就是“两片前挡 + 两块格栅”。我按 `bus_spec.py` 粗算：眼睛到前挡约 1.4 m，车中线上的立柱从主座位看大约在 **−21°**，宽 6 cm 时约占 −22.6° … −20.2°。正好落在收音机（−20°/−12°，D-14）后面，夹在坠入深海（−15°）和河伯（−25°）之间，月（−12°）、裂口（0°）、银心（−30°）都碰不到。所以**两片前挡和你的 15/15 应该是兼容的**，请用 `viewcheck.py` 量准。
- 第 7b 幕刹停时，殿门从 −15° 走到 −27°（F6 → F7），会从这根立柱后面经过一次，最后停在它左边，空司机座在它下方。这可以当成构图来用，不是缺点。
- 总导演说“窗框和立柱是画框，比例和粗细要好看”。这根柱子要细（原车的照片里也不粗）。
- 如果量下来压到目标，退回你现在的整块包角挡风，其余照 PAZ 做。

## 4. 外观：照原车做

1. **轮廓**：面包一样的圆车顶；**车顶两侧的斜面窗要做**，和车窗同一个 `Lanbai/BusGlass`。它们会改变第 4 幕之后车厢里的天光、第 8、9 幕侵蚀的读法，量视窗时一起算进去。
2. **前脸**：两片前挡（3.3），上方一排小眉窗（`ref/PAZ_06`）。**目的地牌放进中间那扇眉窗**，正好是你的 `DEST_BOX`：外看正字「蓝白」，内看反字（圣经 §4.7），第 11 幕空白。
3. **天窗**：你的紧急逃生顶窗（0.6 × 0.6，`SKY_C`）就当成 PAZ 车顶最前面那个舱口，换成透明玻璃；铰链、旧胶条、框角滴水（圣经 §4.6）。
4. **涂装**：照卡卢加那辆的分法（`ref/PAZ_02`）：腰线以上白，以下蓝，**两块“眼睛”格栅外面一圈蓝描边**。颜色用圣经的：上 `#D8D2C2`、下 `#34506E`；车身的金属腰线就是圣经那道 20 mm 银线。
5. **灯**：车头是成对的圆灯，一白一黄（`ref/PAZ_05`）。**只亮白的两盏**（卤素 3200 K，圣经 §4.9），黄的做成不亮的灯罩：暖色是配给的。
6. **去掉国籍**：红色厂徽、车牌、路线号、所有西里尔字母和厂牌字样都不要（圣经 §6·1“要避免”）。轮廓、灯、格栅都保留，那是它的脸。
7. **做旧**：锈照照片里的位置长（轮拱、门槛、门边、前保险杠，`ref/PAZ_04`、`ref/PAZ_07`），再加圣经 §4.9 的雨痕、泥点、掉漆；车顶的白漆氧化发粉（光滑度 0.28）。

## 5. 车厢：照圣经 §4 和你已经做的，不照原车

- 座椅、穿孔顶棚、不锈钢立柱、凸点橡胶地板、管灯、窗帘，照圣经 §4.2–§4.8，还有你已经做的 `gen_textures.py` 和 D-14 的收音机位置。原车内饰只用来参考结构。
- **发动机盖**：前置发动机的车，司机右边有一块机盖鼓包。放得下的话留着，“空着的司机座”那一角会更像一辆真车。别挡住收音机和 D-14 的视线。
- 车顶两侧的斜面窗从里面看，是顶棚两边一排倾斜的玻璃，和你的“|x| > 0.90 起弯到窗顶（风道罩）”要合起来想。
