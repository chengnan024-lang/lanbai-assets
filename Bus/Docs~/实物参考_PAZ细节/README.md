## 0. 先看这几样

1. **Flickr 上 trolleway 拍的“莫斯科复古巴士 PAZ-672 Н308НР40”整套照片**（CC BY 2.0，约 60 张，其中二十来张是车内）。这是目前能找到的**最好的 PAZ-672 车内照片**：顶棚、斜面窗的内侧、风栅、灯具、座椅、折门的里面都有。下面第 1 节逐张列了链接和看点。这些照片**没有放进仓库**，原因见下面“为什么有的只给链接”。

4. Kolesa.ru 的 672M 试驾：司机区和车内照片最全（有版权，只给链接），文字要点摘在第 3 节。

### 为什么有的只给链接

- **放进仓库的**：只有 Wikimedia Commons 上自由授权的照片（CC BY / CC BY-SA / CC0），每张都写了作者和授权（第 4 节，以及 `sources.json`）。
- **Flickr**：照片本身是 CC BY 2.0，允许转载，但 Flickr 的图片服务器不让我这边的程序下载。我没有去绕开它的限制。小楠在浏览器里打开链接、点“下载”就行，署名写 trolleway 即可。

- **Commons 还有几张在排队**（Wikimedia 对这台机器限流）：PAZ-3201 打开的机盖、车底和车轮、雪地里的车尾、切尔诺贝利那几辆废车的骨架。到了会再补一次提交。

## 3. 文字资料（只摘事实；原文有版权）

**Kolesa.ru《Хороший автобус уехал без нас: тест-драйв ПАЗ-672М》**：<https://www.kolesa.ru/test-drive/horoshij-avtobus-uehal-bez-nas-test-drajv-paz-672m>
- **司机区很高**，只有一个窄踏步，而且因为轮拱往前挪了；座椅和方向盘之间很挤，**司机身后是一道隔板**。
- **仪表台**和某些 Москвич-412 上的一样。
- **发动机在司机右边**，机罩（кожух）在很多车上都被压凹了。
- **方向盘**的轮缘细，而且相对座椅偏右。
- **车门是真空助力**，司机用一个手柄开关，手柄位置别扭（有的司机会挪走它）。
- 车厢里：座椅有结实的横杆；有叫司机停车的按钮；推拉气窗上的窗扣形状像马自达的转子；**车顶舱口用杠杆开关**。

**Автомодельное бюро《ПАЗ-672М》**（模型爱好者整理的厂史）：<http://denisovets.ru/paz/pazpages/paz672m.html>
- 672M（1982 年 12 月投产，到 1989 年共 90,645 辆）和 672 的确定区别**都在车内**：前部暖风风道面板上盖一条**宽的绗缝人造革隔热层**；**座椅扶手顶端加了管状的防撞包覆**；内饰板换成**带装饰花纹的硬质纤维板**（ДВПО）。
- 车身标准色是“金黄赭色”（золотистая охра）。缺这种漆时，也出过**白色或浅灰车身配红色或蓝色裙边**的批次，所以**白上蓝下本来就是 672M 的出厂配色之一**。
- 1976 年起前门上方加了一盏照明灯；1978 年起换了新灯具（转向灯和示廓灯改成矩形）；侧窗可以当紧急出口。

**其他**
- 1980 年版《Автобус ПАЗ-672. Руководство по эксплуатации》（第 8 版，240 页）有“操纵件和仪表”一章的线图：<https://dokumen.pub/672-8nbsped.html>（版权状态不明，只给链接）。
- 二手文章说司机区用帘子或轻隔板和车厢隔开，司机有自己的门（[pikabu](https://pikabu.ru/story/avtobus_paz672__rodom_iz_sssr_11638174)、[carsweek](https://carsweek.ru/news/News_in_the_world/1293144/)，没有核对）。
- **YouTube 的走查视频**：这台机器打不开 YouTube，所以**没有截图时间点**。可以搜“ПАЗ-672 обзор салона”。

## 5. 现成的 PAZ-672 3D 模型

**先说结论**：
- **免费、授权干净（CC BY）**的只有 Sketchfab 上的几个，质量中等，没有一个能直接当成品车。
- 质量够、带车内的都是**付费**的。它们的授权（Sketchfab Standard、3d-baza、RenderHub）都要求“**不让别人把模型提取出来**”，而 VRChat 世界的资源包是能被拆的，这一点有风险，买之前要读全文。
- 我们的车已经偏离原车（门在前轴前面、车宽、眼位合同），整车拿来也要大改。**更实际的用法**是当参考，或者只拆零件用（座椅、方向盘、灯、格栅）。

**授权要点**
- **CC BY**（#1–#4）：可以用在免费的 VRChat 世界里，在片尾或公告板上署作者名和链接就行，也可以改。
- **Sketchfab Standard / Free Standard**（#5、#6）：不许让第三方把模型提取出来，不许单独再分发。VRChat 的资源包可以被拆，算是灰区。
- **RenderHub 的 IP Restricted**（#6）：只限编辑用途（新闻、评论之类），**不能用在世界里**。同一个模型在 Sketchfab 上卖的是 Standard。如果要买，从 Sketchfab 买，并且再读一遍全文。
