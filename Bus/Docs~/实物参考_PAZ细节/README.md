## 型号怎么认（10-24 补：每条都加了“型号”一栏）

我们做的是 **672M**（D-28）。照片上的车能分到哪一档，看下面几条：

| 依据 | 说明了什么 | 出处 |
|---|---|---|
| 车内铭牌写 **ПАЗ-672М** | 确定是 672M | `D08` |
| 车内三样（**672M 和 672 确定的区别全在车内**）：① 前部暖风风道面板上一条**宽的绗缝人造革隔热层**；② **座椅扶手顶端的管状防撞包覆**；③ 内饰板是**带装饰花纹的硬质纤维板**（ДВПО） | 看得见这几样就是 672M；看得见、但没有，多半是 672 | [模型局](http://denisovets.ru/paz/pazpages/paz672m.html)、[Kolesa](https://www.kolesa.ru/test-drive/horoshij-avtobus-uehal-bez-nas-test-drajv-paz-672m) |
| **矩形转向灯（和示廓灯合在一起）、竖排方形尾灯** | 只说明是 **1978 年以后**的车，分不出 672 和 672M。“矩形灯 = 672M”是常见的误解 | [俄文维基「ПАЗ-672」](https://ru.wikipedia.org/wiki/ПАЗ-672) |
| 圆形转向灯、圆形尾灯 | 1978 年以前的 672 | 同上 |
| 车身是“金黄赭色”（золотистая охра） | 672M 的标准色，但投产前就开始用了，**只算弱证据**；缺漆时也出白色或浅灰车身配红或蓝裙边 | 模型局 |
| 只有一扇乘客门（前门） | 672M 的单门版、PAZ-3201 或 672Г；后轮单胎、离地高的是 3201 | 俄文维基 |
| 车顶没有斜面窗 | 672С（北方型）、672Ю（热带型）、672Г（山地型），不是我们的车 | 俄文维基 |
| **672А** | 1967–68 年只造了 2 辆的实验性游览车（顶棚减轻、没有侧窗），照片里基本不会碰到。这一批没有一张是 672А | 俄文维基 |
| 仪表台：横条速度表、和 Москвич-412 同款 | Kolesa 说 672M 用的是这种，但没说 672 不用，**分不出** | Kolesa |
| “ПАЗ-672Б” | 技术文件里没有这个型号，是对 1970 年代改款车的误称 | 俄文维基 |

**结论**：这一批里能确定是 672M 的只有 `D01`–`D03`（看 Commons 标题）和 `D08`（看铭牌）。其余多数是“1978 年以后的 672 或 672M”，**外观和 672M 没有可见的差别**。差别只在车内那三样：照“看不出”的车内照片做的时候，**把那三样按 672M 加上**。trolleway 那辆车的座椅是后来换的红色人造革，不是原厂的样子。

## 3. 文字资料（只摘事实；原文有版权）

**Kolesa.ru《Хороший автобус уехал без нас: тест-драйв ПАЗ-672М》**：<https://www.kolesa.ru/test-drive/horoshij-avtobus-uehal-bez-nas-test-drajv-paz-672m>
- **司机区很高**，只有一个窄踏步，而且因为轮拱往前挪了；座椅和方向盘之间很挤，**司机身后是一道隔板**。
- **仪表台**和某些 Москвич-412 上的一样。
- **发动机在司机右边**，机罩（кожух）在很多车上都被压凹了。
- **方向盘**的轮缘细，而且相对座椅偏右。
- **车门是真空助力**，司机用一个手柄开关，手柄位置别扭（有的司机会挪走它）。
- 车厢里：座椅有结实的横杆；有叫司机停车的按钮；推拉气窗上的窗扣形状像马自达的转子；**车顶舱口用杠杆开关**。

**Автомодельное бюро《ПАЗ-672М》**（模型爱好者整理的厂史）：<http://denisovets.ru/paz/pazpages/paz672m.html>
- 672M（1982 年 12 月投产，到 1989 年共 90,645 辆）和 672 的确定区别**都在车内**：前部暖风风道面板上盖一条**宽的绗缝人造革隔热层**；**座椅扶手顶端加了管状的防撞包覆**；内饰板换成**带装饰花纹的硬质纤维板**（ДВПО）。
- 车身标准色是“金黄赭色”（золотистая охра）。缺这种漆时，也出过**白色或浅灰车身配红色或蓝色裙边**的批次，所以**白上蓝下本来就是 672M 的出厂配色之一**。
- 1976 年起前门上方加了一盏照明灯；1978 年起换了新灯具（转向灯和示廓灯改成矩形）；侧窗可以当紧急出口。
- **勘误**：上一版第 2 节写“转向灯 672M 起改成矩形”是错的。俄文维基明确说，矩形转向灯和竖排方形尾灯是 **1978 年**分两步换上的，早于 672M（1982 年 12 月）；把它当成 672M 的标志是常见的误解。

**其他**
- 1980 年版《Автобус ПАЗ-672. Руководство по эксплуатации》（第 8 版，240 页）有“操纵件和仪表”一章的线图：<https://dokumen.pub/672-8nbsped.html>（版权状态不明，只给链接）。
- 二手文章说司机区用帘子或轻隔板和车厢隔开，司机有自己的门（[pikabu](https://pikabu.ru/story/avtobus_paz672__rodom_iz_sssr_11638174)、[carsweek](https://carsweek.ru/news/News_in_the_world/1293144/)，没有核对）。

## 6. 第四批（10-24 晚）：PAZ-672M 的车内，先看座椅

> 总导演：车现在照的座椅参考是 Fortepan 里 1960 年代的车，不是 672M。这一节回答“**672M 的座椅到底什么样**”，另外补立柱、侧窗窗扣和司机区。
> trolleway 那 8 张（以及同一辆车的另外 3 张车内）**现在放进仓库了**，在 `flickr/`，CC BY 2.0。授权限制更多的放在 `flickr/ref_only/`。**全部保留版权的只给链接**，原因在 6.5。

### 6.1 先说结论：座椅五问

最可靠的 672M 车内照片是 **Kolesa.ru 试驾的那辆**（1989 年造，最后一批 672M，RetroBus 修复，**确定是 672M**）。照片有版权，只给链接（6.3）。trolleway 那辆（Н308НР40）门边铭牌上看得见“…З-672”，**后面没有 М，多半是 672**，而且修复过、座椅重新包了红色人造革。两辆车的**座椅结构一样**，只有颜色和管套不一样。

| 问题 | 672M（Kolesa 那辆） | trolleway 那辆（多半是 672） | 我们做的时候 |
|---|---|---|---|
| **靠背顶上的杆：横贯，还是只在过道角？** | **横贯。** 靠背框是一根弯管：两头竖上来，到顶弯过去，横跨整个靠背宽度 | 一样，横贯 | **横贯整个靠背** |
| **杆上的包覆** | 横的那一段整条套着**黑色人造革管套**，看得见一道接缝；**两头弯角不包，露出漆过的管子**。Kolesa 文章把这条列为两者的区别之一：672M 和 672 不同在“верхушкам поручней пассажирских сидений с травмобезопасным трубчатым покрытием”（乘客座椅扶手的顶端，带防撞的管状包覆） | 横的一段整条套着**红色**软套，和座椅同色，像修复时做的；过道角的弯头露管、漆掉了 | **黑色管套，套住横的那一段，两头弯角露管** |
| **管子是不是镀铬** | **不是。** 漆的，浅青绿色，和司机区、门的颜色一样 | 不是。漆的，奶油色 | 漆管。颜色按圣经 |
| **座垫和靠背的缝法** | 枣红色人造革，**每块都是整块，不分格、没有竖条或横条**；边上一圈**米白色嵌线**（滚边）。座垫厚，前沿圆。靠背的人造革从上沿包过去，管套就压在它上面 | 红色人造革，整块，边上嵌线 | **整块 + 一圈浅色嵌线**，不要绗缝条纹 |
| **靠背高度** | 没有找到写尺寸的资料。照片上，靠背顶（连管套）大约和侧窗下沿齐平，或者略低一点 | 一样 | 靠背顶 ≈ 窗台线，宁低勿高 |
| **背板（靠背背面）** | 和管子同色的**浅青绿色一整块板**，四边压出一圈凸边、中间凹下去（像冲压的薄钢板），边上有几个小螺钉 | **白色**一整块板，上沿一排小圆头铆钉（或螺钉），下沿是一道浅弧；有旧孔和磕痕 | 照 672M：一整块四边压出凸边的板，和管子同色，边上几个小螺钉 |

还有两点：
- **轮罩上的单座**（trolleway 那辆，`F04`）：方方的一块红色靠背，**没有顶杆也没有管套**，坐在一根管子撑起来的座架上；旁边立柱伸出一根横杆，挡在靠背旁边。
- **车尾一排五人长椅**（`F03`、Kolesa `salon-3`）：一整条靠背、一整条座垫。

### 6.4 勘误（改了第 1 节的说法）

- `31583339885`（现在的 `F08`）：第 1.3 节说它“我判断是推拉气窗的窗扣”。**不对**，它是**顶棚风口的调节拨杆**：奶白色的百叶格栅，一条槽里伸出一个球形拨杆，背后是木纹顶棚，和 `F06` 里风口一头挂着的小球是同一个东西。真正的窗扣看 Kolesa `salon-7`。
- trolleway 那辆车：第 1 节写“型号：看不出”。现在多了一条证据：`F05` 门边铭牌上看得见“…З-672”，后面没有 М，**多半是 672**（铭牌有一部分被手挡住，所以只说“多半”）。
