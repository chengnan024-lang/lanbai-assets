## 技术 · 建议（采纳的）

- FFT 法线的斜率符号反了：改成 `s = −n.xy / n.z`（和 Gerstner 同号），cginc 与 numpy 一起改。统计上看不出，参考图没重渲。
- 法线贴图各向异性 4 → 1：shader 按 mip 估“已被平均掉的斜率方差”，前提是 mip 各向同性。
- `_Udon_ReflCube_HDR` 没设时退回线性（不再全黑）。
- 透明 FSE：`Docs~/fse_ceiling.json`。外环 ≤ 0.03 FSE；内盘只在溶化的 9 s 里混合（正前 0.38、仰 35° 0.97）。
- `_DissolveTime` 要写三个材质：接口文档 §4 已写明。
- **没采纳 / 推到第 7a 包的**：EV 线性 alpha 按加雾前的颜色解（雾在头顶 < 3%，误差远小于逐像素余量：K5 最坏 1.27 EV / 2 s，限 1.8）；穹顶的 `discard` 关掉 early-Z（驱动只在水下开它的 renderer，`discard` 只是保险）；深处雾饱和后水面仍全量着色（第 7a 包里按深度关 renderer）；顶点压缩下 SEED 的出生时刻精度（CONTROL §6 第 8 条已要求 TexCoord 不压缩，7a 搭建脚本生成的网格本来就不压缩）；焦散图集每格无留边（`tex2Dgrad` 用连续导数，mip 缝已避开；双线性只混相邻一帧的 1 texel，看不出来）。

## 与评审的分歧

1. **APL 的目标**：圣经 §2 的 APL 是**正前方**的画面平均；K2（仰 60°）、K3（俯 45°）是看水面的特写，美术审稿拿正前方目标比。第 7a / 7c 包会出带车壳的正前方帧再对 APL。
2. **K1 / K4 / K5 的天**是替身，海映出来的“天”的亮度和结构（云盖、真暮天）不归海；海的部分（闪光路、镜带、天花、溶化）照圣经做了，天的数要等云 / 天空。
3. **K3 窗缘的颤动**：F8b 起波已降到 30%（`_WaveAmp 0.3`），剩下的颤动是有意留的（“随着底面的波微微颤动”）。
