# 陌生人测试 · 第 1 轮（640 px，不给任何背景，原话）

- img_1 = `03_K2_r03`（7a 斯涅尔之窗，仰 60°）：“从水下向上仰望水面的画面，浅蓝的天光透过起伏的水面，下方是深蓝的水体，感觉清澈、明亮、安静而开阔。眼睛最先落在浅色天光与深蓝水面交界的那条碎裂的波纹边缘，尤其是右下角那些被阳光照得发白的亮斑。” → **读对了**（水下仰望、天光透过水面）。最亮点落在窗边被太阳照白的碎片上，不在窗心。
- img_2 = `12_K3_r13`（7c 倒置的窗，俯 45°）：“黄昏或夜晚的一片水面（或类似弧形的球面），顶部是接近黑紫色的暗空，弧形边缘上有一抹暖橙色的光，下方是深蓝色的水体，感觉幽暗、静谧、有点神秘孤寂。眼睛最先落在弧形顶端正中那团暖橙色的光斑上。” → 最亮点 **对**（金弧）；但**读反了**：窗外的暗玫瑰镜面被读成“黑紫色的天”，窗里的天被读成“水”。
- img_3 = `18_K4_r06_35`（第 8 幕天花，仰 35°）：“几乎没有具体物体的渐变画面，上半部是深藏青的夜空，下半部渐变为暖橙或沙色的地平线光，像日落或黎明的天色。” → 天花读成了天（没有“水 / 镜面”的线索）。
