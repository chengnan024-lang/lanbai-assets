### 2. 车厢的焦散（§4.8）怎么接

车厢 shader 只要 include 一个文件、调一个函数：

```hlsl
#include "Assets/Lanbai/Common/Shaders/LanbaiCaustics.cginc"     // 文件在 Common（第二批第 4 条），不在 Sea
// posWS 世界位置，nWS 世界法线（单位）。返回线性的加光（直接加到 emission / 漫反射之后的颜色上，乘反照率）。
float3 c = LanbaiCabinCaustics(posWS, nWS) * albedo;
```

函数里做的就是圣经 §4.8 那一句：
- **投影**：世界 XZ 平面投影（7c 不变：仍然是 XZ，只是取“朝下”的面）。
- **朝向**：`_Udon_Caustics.y = +1` 时只照朝上的面（`saturate(nWS.y)` 的 1.5 次方），`−1` 时只照朝下的面（座椅靠背和上墙的**下表面**，`saturate(−nWS.y)`）。
- **两层取最小**：同一张序列帧在 0.6 m 与 1.1 m 平铺各采一次（不同的帧相位和漂移），取 min；帧率 0.3 Hz 一圈（图集 64 帧 = 19 帧/秒，帧间插值）。
- **强度**：× `_Udon_Caustics.x` × `_Udon_CausticsColor.rgb`。深度衰减（水面 1、15 m 深 0）**驱动已经算进 x 里**，shader 不再算。
- 顶棚的破洞：焦散“从破洞里落下”是自然的结果（被侵蚀掉的顶棚不再挡；我们不做阴影，所以车厢里朝上的面在 7a 都会有焦散——这正是圣经要的“焦散倾泻”。如果你觉得车头底下也有焦散不对，可以乘你自己的天窗距离遮罩）。
- 不需要 GrabPass、不需要深度图。单眼 / 双眼一致（世界锚定）。
- 7c（F8c 902.16 起）：驱动把 y 设成 −1，x 随窗里的暮光 0 → 1（→ 921.4）。

我这边给的读数（S7a 下按调色套件的引擎算）：座椅上的焦散亮处屏幕 `#ACD4ED`，填 `#9FCBFF @ +1.46`。`_Udon_CausticsColor` 的默认值写在驱动里，你按灰卡对。
