# 灯与杆 · lookdev 简报（第 1、2、11、12 幕）

写的人：云端会话「灯与假醒」（分支 `pkg/lamps`），2026-10-22。
这一页回答三件事：**做成什么样**（形制）、**要达到什么**（圣经的屏幕目标）、**怎么量**。迭代都对照这一页。

## 1. 形制考据（真，但不属于任何具体地方）

### 1.1 这条路上为什么是这样的灯

圣经要的是一条**乡道**：两车道、湿沥青、只有白色中心虚线，路边是水田和零星农家。这类路在东亚（以及大半个世界）上最常见的路灯不是独立的灯杆，而是**挂在配电线杆上的“眼镜蛇”灯头**：电力公司的混凝土杆本来就沿路走，在杆上 6–7 m 处用抱箍固定一根短钢管臂，臂端套一个压铸铝灯头，灯头里是高压钠灯。所以第 2 幕的路灯、电线杆、电线是**同一件东西**：灯装在电线杆上，电线从一根杆垂到下一根杆。这是“真”的来源，也让套件只有一种杆。

“不属于任何具体地方”的做法——**只留下全世界共有的形，去掉一切地域记号**：
- 没有杆号牌、没有喷涂编号、没有警示标志、没有广告、没有拉线的黄色护套、没有变压器、没有街道牌。
- 灯头不是任何一款产品：取 1960–90 年代眼镜蛇灯头的共同轮廓（扁长的铝壳、前端圆鼻、下面一个下垂的棱镜玻璃罩、顶上一个光控器），比例自己定，没有铭牌、没有品牌凸字。
- 绝缘子用最普通的白色针式瓷瓶（中、日、欧、北美都长这样），不用有地域特征的茶色釉或特殊形状。
- 横担用镀锌角钢（全世界最常见）。

### 1.2 离心混凝土杆（圣经 §5.4）

| 项 | 取值 | 依据 |
|---|---|---|
| 工艺 | 离心浇注的环形混凝土杆（中空，壁厚约 50 mm） | 圣经 §5.4、§8.2 |
| 高 | 9.0 m（地上）；埋深不建模 | §5.4 |
| 直径 | 根 Ø280 → 顶 Ø190 mm，线性锥度（1:100） | §5.4（国标 1:75 锥度的杆也常见；以圣经为准） |
| 表面 | 离心杆特有的**光滑、略带水泥浆光泽**的面；纵向的模缝两条（180° 对开钢模的合缝，2–3 mm 宽的细棱）；零星的气孔（1–3 mm）；顶端一个封口帽；根部 0.6 m 的**溅水带**更暗、带一点青苔 | 实物观察的共性 |
| 雨痕 | **竖向雨痕**（§5.4）：从横担、抱箍、穿钉孔往下流的**锈水痕**（细、长、断续），以及整根杆上更淡的、宽的灰色流痕 | §5.4 + 共性 |
| 反照率 | 干 0.22 / 湿 0.12（线性），湿光滑度 0.35 | §5.4 |
| 穿钉孔 | 杆身每隔约 0.5 m 一对 Ø20 mm 的预留孔（固定横担和抱箍用），大多空着 | 共性 |

### 1.3 横担、绝缘子、电线

- **横担**：L63×6 镀锌角钢，长 1.5 m，离杆顶 0.3 m；两根 U 形抱箍 + 一根斜撑（扁钢）。镀锌层老化成暗灰（金属度 0 的“积垢锌”，反照率 sRGB ≈ 95；只有边棱上 1–2 px 露出金属亮）+ 局部锈（`#6B3A1E`）。
- **绝缘子**：针式瓷瓶 3 只（横担两端 + 杆顶一只，经典三角排列），白釉 `#D6D8D4`（≤ 235），光滑度 0.88，湿了更亮。高 130 mm、裙边 Ø110 mm。
- **电线**：3 根铝绞线（Ø10 mm），黑 / 深灰、光滑度 0.6（圣经 §5.4）。下垂按**悬链线**：跨距 L、弧垂 f ≈ 1.5–2.5% L（32 m 跨约 0.6 m，40 m 跨约 0.8 m）。电线在 Unity 里用一个专门的细线 shader（§4.4），不能用细圆管（远处会断成虚线闪烁）。
- 雨夜里电线是**看得见光**的：靠近灯的那几米被灯勾出一条细亮线（§5.4 “近灯处被灯管勾成细线”），离灯远处是剪影。

### 1.4 眼镜蛇钠灯头（第 2 幕、第 11 幕）

| 项 | 取值 |
|---|---|
| 灯头尺寸 | 长 0.68 m、宽 0.32 m、高 0.18 m（中型，250 W 级） |
| 壳 | 压铸铝，原来是浅灰漆，雨淋三十年后：粉化的哑光灰 `#7C807E`（金属度 0；顶面更粉 `#8A8D8A`，光滑度 0.35；侧面 0.45）。顶上的光控器是一个 Ø70 mm 的灰白塑料帽。 |
| 罩 | 下垂的棱镜玻璃罩（"drop refractor"）：椭圆、深 0.09 m；外表面一圈圈的棱（细的环形棱镜纹），内表面的竖向折射棱。玻璃有**一层黄褐色的积灰**，下沿积水挂珠。 |
| 发光体 | 高压钠灯的弧管：罩里一根 0.10 m 长的细亮线（屏幕上是灯头里最亮的一小段，核心发白），被棱镜打散成一团橙光。**整个玻璃罩都在亮**，但不均匀：弧管周围最亮，罩边缘 30–50%。 |
| 臂 | Ø48 mm 钢管，1.0 m（§6·2 “短臂 1.0 m”），向上仰 8°，根部两道抱箍；臂端是灯头的套管座。漆掉成锈褐。 |
| 安装高度 | 灯头下沿离路面 6.5 m（§6·2）；第 11 幕倒挂时离路面 7 m（§6·11） |

**颜色**：钠灯 2050 K，光色 `#FF941D`（§4.8）；发光体在 S2 下屏幕 `#EDAD77`（填 `#FF7B00 @ +1.14`，×T0 1.51，calib §B）——**它在 bloom 里，但不是第一亮点**（第 2 幕的第一亮点是车灯隧道 / 钠灯一起，§1.3 第 1 条）。第 11 幕倒挂灯头屏幕 `#F2B070`（§6·11 色板）。

### 1.5 站灯（第 1、12 幕，§5.4）

- 同一根离心杆（9 m），4.2 m 高处一根 1.2 m 钢臂，挂**搪瓷槽形反射罩**（外 `#3E4A45` / 0.6，带崩瓷；内白搪瓷），罩下一根**裸露的 1.2 m T8 灯管**（Ø26 mm）：发光屏幕 `#EEF5F7`（填 `#E7FEFF @ +1.03`，×T0 1.60），两端 3 cm 发黑 `#8C9396`。
- 槽罩两端是半圆的端板，灯座是白色电木；罩外沿积水，**灯臂下沿是一个滴水点**（雨套件 §7：唇口在灯管槽外端最低点，`fallHeight` 3.90 m）。
- 这根杆在站牌一侧（右侧路肩），电线 3 根垂到 40 m 外的下一根杆（§5.4）。

### 1.6 第 11 幕 · 倒挂的灯（§6·11）

- 暗海悬在路上方 **80 m**；灯杆从海里**倒垂**下来，灯头在路面上方 **7 m**、朝下；灯杆上升 **73 m** 刺穿海面。左侧路肩外、离眼睛 ≥ 10.5 m，间距 32 m。
- 本地时间轴的 `lampFlipHeight = 17` 是**占位**（把 9 m 的杆翻过来挂在 17 m）。圣经 v2.1 是 80 m 的海、7 m 的灯头。按 CONTROL §3 以圣经为准；差异写进 `给总控.md`。
- 形制：**同一个灯头、同一种杆**，只是杆被拉长到 73 m（离心杆不会有这么长——这是梦）。杆往上走进雾里、在海面附近消失；海面在杆刺入的地方有一圈很淡的环形光（灯照在海的底面上：§6·11 的“海面钠光闪烁”来自解析 GGX）。
- 横担和电线：杆的“顶端”（横担、瓷瓶）在**下面**，就在灯头上方 1–2 m；电线从一根杆到下一根杆**向上**弯（悬链线倒过来）。它不是提示，是同一套东西被翻过来以后自然的样子——只有抬头细看才发现。
- 路是干的（`_Udon_Wetness` = 0）、略微太干净；灯池在干路上屏幕 ≈ `#3B3029`，没有光带。

**规则（量）：**
- §1.3 第 1 条：每帧一个最亮点。第 2 幕最亮的是近处钠灯头与车灯隧道；**电线、杆、横担永远不能抢**（杆在灯下 60–80，横担与瓷瓶 ≤ 120）。
- §1.3 第 3 条：暖色是配给的——钠灯是允许的暖；杆与壳的阴影里不能出现暖色。
- §1.6 反照率纪律：非金属 sRGB 48–231；金属 ≥ 150。
- §1.8：灯头经过时眼睛处角速度 ≤ 60°/s（v ≤ 1.05·d：10 m/s → d ≥ 9.5 m；圣经要 ≥ 10.5 m）；扫光每 3.2 秒一次、1.0 秒，是“扫”不是“闪”；钠灯稳，不闪。
- §1.9：每盏路灯（杆 + 横担 + 瓷瓶 + 臂 + 灯头）LOD0 ≤ 3 000 三角形，LOD1 ≤ 900，LOD2 ≤ 200；一屏同时 ≤ 8 盏可见；电线每跨 1 个 draw（或合批）。

## 3. 怎么量

1. **固定机位**：主座位眼位。本包用 `Gate/GateLayout_v2.json` 的 `cameras.U7.eye_bus_relative` = **(0.55, 1.70, 2.05)**（车坐标，Unity：x 右、y 上、z 前），桌面 1920×1080、水平 90°。`LB_Journey.heroEye` = (0.70, 1.77, 0.20) 不同，README 写明。
2. **PPv2 模拟**：`Grading/Tools~/engine/ppv2_engine.py`（引擎参数 `grades_engine.json`），bloom 用同一套参数（`Art/tools/lens_cine/ppv2.py` 的 `bloom_layer`）。场景线性 EXR → bloom → LUT。
3. **量**：APL（Rec.709 平均 luma）、最亮 0.1% 像素在哪（是否是灯头 / 车灯）、钠灯头像素的中位色 vs `#EDAD77`、灯池的显示值、杆在灯下的显示值、暖色是否进了阴影（亮度 < 20 的像素里 h_ab 30–90 且 C\* > 8 的比例）、紫的占比（§1.3 第 4 条）。
4. **评审**：每轮两个独立 agent（美术、技术）+ 一个 640 px 缩略图的陌生人测试。陌生人测试想听到的话：
   - 第 2 幕：“雨夜，从一辆车里，橙色的路灯从左边一盏盏过去。”
   - 第 11 幕：“夜里的路，路灯是从上面倒挂下来的，头顶是一片水 / 海。”
   - 站灯：“雨夜里一根电线杆上一根冷白的灯管。”
