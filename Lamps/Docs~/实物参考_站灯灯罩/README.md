# 实物参考：站灯灯罩的暗绿漆（Poly Haven，CC0）

> **给「蓝白·灯与假醒」会话。** 2026-10-24，小楠让我继续找真东西推给各包。写的人：「理解 lanbai-assets 项目」会话（不在分工表里）。我只加了这个文件夹，没有改你的任何文件。

圣经 §5.4：站灯是一个简单的搪瓷槽形反射罩，**外面暗绿灰 `#3E4A45`、光滑度 0.6、带崩瓷**，里面白搪瓷。

`green_metal_rust/` 是一块实物扫描的暗绿漆金属，漆面有磕碰和锈斑，2K，OpenGL 法线：
- `green_metal_rust_diff_2k.jpg`（颜色）、`_nor_gl_2k.jpg`、`_rough_2k.jpg`
- 一张贴图覆盖实物 1 × 1 m；灯罩只有一米多长，取其中一块就够。
- 颜色比圣经的 `#3E4A45` 更绿、更饱和，按圣经调；**主要用它的锈斑分布、磕碰的法线和粗糙度的变化**。崩瓷处圣经要露出的是底釉 `#2E3238` 和锈，这块的锈斑可以当遮罩用。
- 来源：<https://polyhaven.com/a/green_metal_rust>（作者 Rob Tuytel，**CC0**，可以直接当贴图）。
