# 车厢 shader → 总导演 / 总工程师

2026-10-24 · 车（`pkg/bus`）· 车厢 shader 包 v1（`Cabin/`）。都是要你定或者要别的包配合的事，按要紧的排。

## 1. 侵蚀阈值公式：圣经原文和它下一句话打架，请定

圣经 §4.8：阈值 = fade − 0.45·(1 − 高度归一) − 0.25·(前方程度) − 0.35·exp(−到天窗距离 / 0.8 m)，下一句“**侵蚀从天窗的边开始，然后车顶与车头**”。照字面减，前方程度越大、离天窗越近，阈值越低——天窗边和车头**最后**才走，正好反了；车尾顶棚第一个走，第 8 幕末过道地板已经没了 79 %。

我做了一个开关 `_ErodeForm`：
- **0（默认，按“下一句话”）**：后两项取补（1 − 前方程度、1 − exp(…)），系数不变。
- **1（照字面）**。

`Cabin/Tools~/cabin_numpy.py` 量的各区被侵蚀掉的比例（和 shader 同一套 FBM、同一个噪声映射 `_ErodeNoiseRange` = (−0.20, 0.25)）：

| 区域 | fade 0.07（≈387 s） | 0.25（F5） | 0.65（第 8 幕末） | 0.97（第 12 面镜） |
|---|---|---|---|---|
| 默认：天窗边 0–0.3 m | 39 % | 77 % | 100 % | 100 % |
| 默认：前半顶棚 | 15 % | 50 % | 100 % | 100 % |
| 默认：后半顶棚 | 0 | 0 | 60 % | 100 % |
| 默认：上墙 | 2 % | 18 % | 53 % | 100 % |
| 默认：座椅 | 0 | 0 | 5 % | 63 % |
| 默认：立柱（`_FadeResist` 0.3） | 0 | 0 | 2 % | 36 % |
| 默认：过道地板 | 0 | 0 | 0 | 46 % |
| 字面：天窗边 | 0 | 0 | 60 % | 100 % |
| 字面：后半顶棚 | 38 % | 85 % | 100 % | 100 % |
| 字面：过道地板 | 0 | 0 | 79 % | 100 % |

默认那一组和 §4.8 表对得上（F5 只有天窗周围开了；第 8 幕末“车顶与上墙没了；座椅、地板、立柱还在”；第 9 幕座椅走、立柱最后）。**请批默认，或者改圣经的公式写法**（两项取补）。

## 2. 全局量：没有新的，但两处类型请登记表写清

- `_Udon_CabinBleach`、`_Udon_CabinFade`：登记表写 float，`LanbaiGlobals.cginc` 生成成 float4（标了 type guessed）。我按 **float4，x = 值、w = 1 已设** 写（`SetGlobalVector`），shader 读 `.x`。请登记表改成 float4。**类型不一致时 Unity 会读不到**（`SetGlobalFloat` 的值不给 float4 的 uniform），所以这条要先定。
- `_Udon_CabinAmbient`、`_Udon_RadioDial`：float4，rgb 线性，a = 1；用 `SetGlobalVector`（不用 `SetGlobalColor`：线性工程里它会再做一次 gamma→线性）。门内驱动也是这么写的，一致。
- 每个客户端自己的座位球（`_SeatSphere`）和 D-26 地板洞（`_HoleOpen`）**用材质属性（MaterialPropertyBlock）**，不用全局量：座位球每个人不同，本来就是本地的。如果你更想要全局量，名字建议 `_Udon_CabinSeat`（xyz 座位中心、w 半径）、`_Udon_CabinHole`（x 0..1），改起来是 shader 两行、驱动四行。

## 3. 本地的 `LB_Journey` 要跟着改的（不改 `LB_Journey` 是规矩，所以写在这里）

1. **管灯曲线**：`ApplyLamps` 是 U5 + 3 秒降到一半；圣经 v2.1 是 **U4h（99.50）→ U5（107.50）降到 0.5**。我的 `_Udon_CabinLightmap` 照圣经，于是 99.5 → 110.5 之间头像补光灯（Journey 写）和车厢（我写）差一点。请本地改 `ApplyLamps` 照圣经，或者批“以 Journey 为准”我改。
2. **闪烁表**：U6 → U9 + 0.45 这一段 `_Udon_CabinLightmap` 读 Journey 的 `_l0 / _l1 / _l2`（`GetProgramVariable`，私有字段，Journey 第 230 行），取平均。**请别改这三个名字**；更好的是 Journey 加一个 `public float tubeLevel`，我改读它。驱动里不另存一份闪烁表。
3. **`SetBusAlpha` 占位要拿掉**：Journey 的 dither 淡出和“alpha ≤ 0.55 关玻璃”是侵蚀 shader 之前的占位。车厢包接上以后，`busRenderers` / `glassRenderers` 两个数组请清空，否则和我的玻璃开关、MPB 打架。
4. Journey 在管灯 renderer 上写 MPB `_Emission`：`Lanbai/Cabin` 的灯罩用 `_EmissionColor × _Udon_CabinLightmap`，那个写入没有效果，也无害；可以删。
5. 驱动只写全局量和材质，**不建灯、不碰灯**（D-24：唯一带阴影的主光是 `RenderSettings.sun = Gate_Lights/Moon`；D-00：Inspector = E）。

## 4. 和门内驱动的交接（D-22 一个时刻一个写的人）

`LanbaiInsideDriver` 在它的窗口 [U9 − 2, U12 + 4] = [177.55, 252.64] 里写 `_Udon_CabinAmbient`、`_Udon_RadioDial`、`_Udon_CabinSlice*`。车厢驱动的窗口是全片，所以在这段里**不写这三个**（`yieldToInside = true`）。分发层的 Report 按窗口会把它列成重叠——是有意的，请在 `Engineering/README_集成.md` 里记一笔。没有门内包时把 `yieldToInside` 关掉，车厢驱动自己写圣经的退路值（4c `#B5C3DB × 0.30`、表盘 ein Lichtchen + D-02）。

## 5. 4c 车窗反射（门内 `给总控.md` 10-24，181 s）和第 5 / 10 幕关玻璃

- `Lanbai/BusGlass` 从车里看的反射 = 车厢立方图 × `_Udon_CabinLightmap` × `_CabinReflGain`。U9 起管灯是 0，所以 Unity 里本来就映不出车后的光唇；我仍然在 [177.55, U12] 把所有玻璃（含车顶两侧斜面窗、天窗、门）的 `_CabinReflGain` 用 MPB 置 0，其余时间夜 1、白天（F0 → 1009.21）0.25（雨套件 §5.2）。**前提**：`_CabinCube` 是只有车、管灯开的车厢立方图，不在门附近烘、不用实时探针。
- 第 5 幕全黑（248.64 → 251.64）、第 10 幕全白（1149.31 → 1178.46）玻璃 renderer 关。
- 雨的驱动如果也往玻璃上写 MPB，`GetPropertyBlock` 先读再写，互不覆盖；但请雨套件确认它没在每帧 `SetPropertyBlock(new …)`。

## 6. 我替圣经补的读法（没有原文，按最近的意思定的；不对就说）

- 第 1 幕出发前（t < 0）收音机表盘 0；t = 0 起调台噪音。
- U3 “6 秒内从 1.5 升到 3 HDR 再回落”：读成 6 秒升、6 秒落，倍数 ×2（填值基准 `#FF7703 @ +0.71`）。
- 7a 的环境色“跟深度”：没读 `_Udon_SeaBus`（Udon 读不回全局量），按时间 F3e → F3e3（开始下沉 → 最后一点蓝熄灭）从浅到深，EV 线性。
- 7c 的“玫瑰光自下”：车厢环境色**保持** `#0F1E30 × 0.3`，玫瑰靠海的两盏玫瑰点光和 Trilight 地。蓝的环境色和玫瑰混是丁香紫（D-17 的教训）。
- 第 8 → 9 幕：F12 → 1009.21（第 9 幕前 8 秒变暗结束）环境色从 `#828BAA × 0.45` EV 线性到 `#232A3A × 0.3`。
- F2h → F5 侵蚀 0 → 0.25 用开根号（前快后慢），这样 ≈387 s 天窗边已经开了洞（默认公式下天窗边 39 %），圣经“≈387 从破洞里看得见斯涅尔之窗”成立；线性的话 387 s 只有 0.02，看不见洞。
- 地板补丁“保留到第 9 幕”读成 §1.8 的“第 9 幕之前 1.2 × 1.6 m 地板始终在”：fade 过 0.65（第 1 面镜）开始放。位置 x −0.16…1.04、z 0.85…2.45（主座位下，往前顶到 D-26 洞的后沿）。
- 座位球“排除到最后一步”：fade 0.97 → 1（第 13 面镜）放。**D-26 的洞压过座位球**（洞的后沿离座垫中心 0.6 m，在 0.9 m 球里）——D-26 是后来的裁决，照它。
- 第 11 幕窗帘：和第 2 幕同一条路，1.5 cm / 0.8 Hz；第 12 幕系着不动。
- 4.5 的“海里向上漂浮 10–20 cm”：0.15 m ± 25 %。翼松开以后的飞走：加速度 1.2 m/s²、最高 6 m/s，方向 = `_Udon_SunDir`（没设时用材质的 `_FlyDir`）+ 一点向上。

## 7. D-08 的限色器落下来的数（`Cabin/Docs~/swatch_d08_limiter.png`）

裂口光 `#B9B6D6` 自己就是 C\* 17.3、h 295（在紫带里，超过 D-08 的 12）。shader 在 ForwardAdd 的平行光（全片车厢层上唯一的附加平行光就是它）上先把**灯色**限到 C\* ≤ 12、色相拉到 290（→ C\* 11.0、h 290，线性 (0.378, 0.382, 0.492)），再对加上去的颜色做 D-21 紫带护栏。照到的车厢面（E 0.8、N·L = 1）：顶棚 C\* 4.2 / h 305、下墙 3.4 / 309、灯罩 7.8 / 284、钢 9.5 / 286、座椅 20 / 13（红，不是紫）；**窗帘 C\* 15.9 / h 275**——蓝的布被冷白照，色相在 230–290 里，但 C\* 超过 12。我没压它：压了窗帘就不是“淡靛”了。要压的话告诉我。
**前提**：Moon 一直是 `RenderSettings.sun`（D-24），裂口光一直是附加平行光；它如果变成 Not Important 进了球谐，限色器就管不到（球谐那部分被车厢环境色替掉了，所以也照不出紫，但也照不亮）。
